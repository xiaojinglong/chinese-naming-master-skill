# 三才五格配置说明

## 一、五格计算（wuge_calc_rules.json）

| 格 | 含义 | 单姓公式 | 复姓公式 |
|---|---|---|---|
| 天格 | 祖上运 | 姓笔画 + 1 | 姓两字笔画和 + 1 |
| 人格 | 主运（核心） | 姓笔画 + 名首字 | 姓第二字 + 名首字 |
| 地格 | 前运（35 岁前） | 双字名：名两字和；单字名：名笔画 + 1 | 同左 |
| 外格 | 副运/社交 | 总格 − 人格 + 1 | 同左 |
| 总格 | 后运/晚年 | 姓名全部笔画和 | 同左 |

**铁律：一律用繁体字形的康熙字典笔画。**

例：「李明」→ 李(7) + 明(8)：天格 8、人格 15、地格 9（单字名+1）、外格 2、总格 15。

## 二、三才配置（sancai_full.json 为主，sancai_125.json 作参考）

本目录提供**两版**三才吉凶表：

| 文件 | 来源 | 特点 | 建议 |
|---|---|---|---|
| `sancai_full.json` | James88/qiming `sancai.txt`（民间姓名学通行文本） | **125 组完整**：每组含三才五行、对应天/地格数字、**完整断语解释**、原文【吉凶】标注 | **主用**（权威解释版） |
| `sancai_125.json` | 五行生克推导（相生 +1 / 比和 0 / 相克 −1） | 125 组、仅吉凶等级 | 交叉参考 |

- 三才 = 天格 / 人格 / 地格的五行属性组合（5³ = 125 种），人格为中枢。
- 推导版判定依据：天→人、人→地两步五行生克打分：总分 ≥ 2 → 大吉；= 1 → 吉；= 0 → 半吉；= −1 → 半凶；≤ −2 → 凶。
- 原文版等级分布：大吉 39 / 中吉 17 / 大凶 33 / 凶多于吉 22 / 吉多于凶 6 / 吉凶参半 4 / 吉 2 / 凶多吉少 1 / 半凶 1。
- **两版口径差异提示**：部分组合判断不同（如 金金木：原文【大凶】、推导【半凶】），**以原文版 sancai_full.json 为准**；该表源文件缺「金金火」1 组，已用推导版补全并注明。
- 示例：天格木、人格火、地格土 → 木生火、火生土 → 两版皆大吉。

## 四、使用流程

1. 姓名（简体）→ 转繁体 → 查康熙笔画（`hanzi_common.json` / `hanzi_full.json`；冷僻字按第五节推算）。
2. 按规则计算天/人/地/外/总五格。
3. 五格笔画 → 查 wuge_1to81.json 得数理吉凶。
4. 天/人/地三格五行 → 查 sancai_full.json 得三才吉凶与断语（回退：sancai_125.json）。
5. 综合评估：三才、五格数理均为取名评分的重要维度（见 02-规则与算法资料/06-候选名字评分规则.md）。

## 五、扩充字库的笔画校验（重要）

- 计算五格时必须用**康熙字典笔画**，而康熙笔画 ≠ 简体笔画 + 简单换算：偏旁在康熙字典中有固定变体笔画。
- 常见变体：氵=4、扌=4、忄=4、辶=4、犭=4、礻=5、王(斜玉旁)=5、衤=6、艹=6、纟=6、钅=8、阝(左/阜)=8、阝(右/邑)=7、讠=7、饣=9 等。
- **完整变体表见 `kangxi_radical_strokes.json`**；本库字库已按此折算（如清=12、瑾=16），扩充新字时必须对照该表核算。

# 干支八字数据说明

## 文件清单
| 文件 | 内容 |
|---|---|
| tiangan.json | 十天干：五行、阴阳、方位、人体部位、意象 |
| dizhi.json | 十二地支：五行、阴阳、**藏干**、生肖、月令、时辰、方位 |
| shengxiao.json | 十二生肖：地支、五行、时辰、月令、方位 |
| nayin.json | 六十甲子纳音表（年柱纳音参考） |
| jieqi.json | **二十四节气表**：12节令（排月柱边界）+ 12中气 + 季节调候提示 |

## 关键规则速览
1. **八字四柱**：年柱（立春为界）、月柱（**以节令为界**，非农历初一）、日柱（公历推算）、时柱（23:00 起为子时，跨日算次日）。
2. **五行统计必须含藏干**：地支藏干计入五行（如寅中藏甲木/丙火/戊土），只数本气会漏五行。
3. **月柱节气表**（12 节令起点）：立春(2/4左右)、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒。**结构化数据见 `jieqi.json`**（含约期、月支、五行旺相、季节调候）；详细排盘算法见 `02-规则与算法资料/01-八字排盘规则.md`。
4. **时辰划分**：子 23-1、丑 1-3、寅 3-5、卯 5-7、辰 7-9、巳 9-11、午 11-13、未 13-15、申 15-17、酉 17-19、戌 19-21、亥 21-23。
5. **纳音**仅作辅助参考（年命），取名补益以**日主五行与喜用神**为核心，不直接按纳音补。

## 数据口径
- 藏干按通行子平法（寅中甲丙戊等），与《渊海子平》《三命通会》一致。
- 阴阳属性按地支本气划分（子为阳水等，传统惯例）。

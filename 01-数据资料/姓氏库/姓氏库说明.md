# 姓氏库说明

## 文件
- `single_surnames.json`：单姓 413 个（含《百家姓》主体 + 常见姓氏）
- `compound_surnames.json`：复姓 53 个（含常见复姓与罕见古姓）

## 每条字段
| 字段 | 说明 |
|---|---|
| surname | 简体姓氏 |
| traditional | 繁体字形（笔画计算以此为准） |
| pinyin | 拼音 |
| strokes_kangxi / strokes_kangxi_each | 康熙笔画（复姓为两字各自笔画 + 合计） |
| wuxing / wuxing_each | 五行属性（常见资料口径） |
| notes | 备注（字源、特殊说明） |

## 使用要点
1. **五格计算用康熙笔画**：天格 = 单姓笔画 + 1（复姓 = 两字笔画和 + 1），人格 = 姓末字 + 名首字笔画，依此类推。
2. **多音姓**：如「单 shàn」「仇 qiú」「查 zhā」「解 xiè」等，已按姓氏读音标注，切勿按常用读音处理。
3. **异体/合并字**：如「郁（鬱 29 画 vs 本字 13 画）」「钟（鍾 17 画 vs 鐘 20 画）」存在两源，已在 notes 备注。
4. **五行口径**：姓氏五行主要用于三才配置分析的天格五行；不同姓名学流派对个别姓氏五行归类不同，建议交叉核对。
5. 扩充：如需全量姓氏（约 800 单姓 + 100 复姓），可参考《中华姓氏大辞典》数据。

## 关于 James88/qiming 的 baijiaxing.txt（未采用）

开源项目 James88/qiming 自带的 `baijiaxing.txt`（百家姓+笔画）经诊断**格式错位严重**：32 组中仅 3 组姓氏与笔画可配对（其余如"组3 姓49 vs 笔画9"明显错位），强行解析会产生错误笔画数据，故**未并入本库**。原始文件保留在 `05-开源项目参考/james88-qiming/data/` 备查。百家姓数据以本目录 413 单姓 + 53 复姓为准（覆盖《百家姓》全部常见姓）。

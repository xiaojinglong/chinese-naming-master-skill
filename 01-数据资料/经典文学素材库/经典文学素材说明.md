## 字段
| 字段 | 说明 |
|---|---|
| word | 可取名的字/词（如「修远」「清扬」） |
| origin | 出处（书名·篇名） |
| quote | 原句（含上下文，方便生成"出处说明"） |
| meaning | 释义与取名寓意 |
| usage | 适用建议（性别/风格） |
| pinyin | 读音（带声调） |

## 使用方式（在 Skill 中）
1. **按风格筛选**：文雅/古风 → 诗经楚辞；大气 → 周易唐诗；婉约 → 宋词；淡雅睿智 → 道德经。
2. **按字筛选**：先把候选字在素材库中反查，命中则输出"字义原理"时附带经典出处（增强文化底蕴，对应 ziliao.txt 的"经典文献索引"用途）。
3. **随机灵感**：从素材库随机取词，作为候选名来源之一（权重不宜过高）。

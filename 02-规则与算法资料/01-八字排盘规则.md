# 01 八字排盘规则

> 用途：由出生公历年月日时，推算出年柱、月柱、日柱、时柱（四柱），形成八字，供五行分析与喜用神判断。

## 一、四柱推算总流程

```
公历出生时间
   │
   ├─ ① 年柱：以【立春】为界（非正月初一）
   ├─ ② 月柱：以【节令】为界（12 节令，非农历初一）
   ├─ ③ 日柱：按公历日期公式/查表推算（精确到日）
   └─ ④ 时柱：按日干 + 时辰推算（五鼠遁）
```

## 二、年柱规则

- **以立春为分界**：立春前出生属上一年，立春当天及之后属新的一年。
- 例：2026 年 2 月 4 日立春（约），2 月 3 日出生仍算乙巳年（2025 年干支），2 月 4 日起算丙午年。
- 干支年 = (公历年份 − 4) mod 60 查六十甲子表（仅作快速参考，精确须按立春）。

## 三、月柱规则（节气划分，关键）

- 月柱以 **12 节令** 为界，不是农历初一、也不是公历 1 日。
- 一年 12 个月对应 12 节令（**节**）：
| 月 | 节令 | 大约日期 | 月支 |
|---|---|---|---|
| 正月 | 立春 | 2/4 前后 | 寅 |
| 二月 | 惊蛰 | 3/6 前后 | 卯 |
| 三月 | 清明 | 4/5 前后 | 辰 |
| 四月 | 立夏 | 5/6 前后 | 巳 |
| 五月 | 芒种 | 6/6 前后 | 午 |
| 六月 | 小暑 | 7/7 前后 | 未 |
| 七月 | 立秋 | 8/8 前后 | 申 |
| 八月 | 白露 | 9/8 前后 | 酉 |
| 九月 | 寒露 | 10/8 前后 | 戌 |
| 十月 | 立冬 | 11/7 前后 | 亥 |
| 冬月 | 大雪 | 12/7 前后 | 子 |
| 腊月 | 小寒 | 1/6 前后 | 丑 |
- **月干推算（五虎遁）**，以年干起月：
  - 甲己之年丙作首（正月丙寅）
  - 乙庚之岁戊为头（正月戊寅）
  - 丙辛必定寻庚起（正月庚寅）
  - 丁壬壬位顺行流（正月壬寅）
  - 戊癸何方发，甲寅之上好追求（正月甲寅）
- 24 节气约期/月支/五行旺相的结构化数据见 `01-数据资料/天干地支与八字/jieqi.json`。
- 精确的节气时刻每年不同，生产环境必须用天文历法库（见文末）计算，不能只按日期。

## 四、日柱规则

- 日柱由公历日期直接推算，与农历无关，也不需要八字算法推导——**直接算干支**。
- 常用算法：
  1. 计算从基准日（如 1900-01-31 为庚子日）到目标日的天数差；
  2. 干支序号 = 天数差 mod 60（天干 mod 10、地支 mod 12）。
- 示例：1900-01-31（庚子日）→ 目标日与该日相差 N 天，则日干支序 = (N) mod 60，庚为第 7 个天干、子为第 1 个地支。
- 注意：**23:00 后出生按次日日柱**（子时换日，此为子平法通行规则；晚子时与早子时两派差异需固定一种口径）。
- 跨世纪、闰年等边界建议直接用成熟库（lunar-python 等），不要手写日期差。

## 五、时柱规则（五鼠遁）

- 时辰按 2 小时一段划分：子 23-1、丑 1-3、寅 3-5、卯 5-7、辰 7-9、巳 9-11、午 11-13、未 13-15、申 15-17、酉 17-19、戌 19-21、亥 21-23。
- **时干由日干推算（五鼠遁）**：
  - 甲己还加甲（甲日/己日子时为甲子）
  - 乙庚丙作初（乙日/庚日子时为丙子）
  - 丙辛从戊起（丙日/辛日子时为戊子）
  - 丁壬庚子居（丁日/壬日子时为庚子）
  - 戊癸何方发，壬子是真途（戊日/癸日子时为壬子）
- 例：丙午日辰时 → 丙日起戊子时 → 子丑寅卯辰顺推：戊子、己丑、庚寅、辛卯、壬辰 → 时柱为壬辰。

## 六、四柱示例

例：2026 年 8 月 26 日 10:00（公历）：
- 年柱：2026 丙午年（立春后）
- 月柱：8/26 在立秋(8/7左右)之后、白露(9/8左右)之前 → 月支申；年干丙 → 五虎遁"丙辛必定寻庚起" → 正月庚寅…七月为丙申？推：庚寅(正月)、辛卯、壬辰、癸巳、甲午、乙未、丙申(七月) → 月柱丙申。
- 日柱：查表/计算得（示例）某干支。
- 时柱：10:00 为巳时；日干 → 五鼠遁推时干。
- （示例为演示口径，实际数值以历法库输出为准）

## 七、实现建议

**不要手写天文算法**，直接使用成熟开源库（均支持节气、干支、生肖、农历）：

| 库 | 语言 | 说明 |
|---|---|---|
| lunar-python / lunar-java | Python/Java | 6tail 出品，功能最全，直接取四柱/节气/生肖 |
| sxtwl | Python/C++ | 寿星天文历，精度高 |
| cnlunar | Python | 含八字、节气、宜忌 |
| lunar（Node 版） | JS | 前端可用 |

取数接口建议：`Lunar.fromYmdHms(year, month, day, hour, minute, second)` → `getEightChar()`（四柱）、`getJieQiTable()`（节气）。

# 02 五行分析规则

> 用途：分析八字五行分布 → 判断日主强弱 → 确定喜用神 → 指导取名补益。
> **核心原则：不是简单的"缺啥补啥"，而是以日主强弱与喜用神为准。**

## 一、五行统计（含地支藏干）

1. 八字四柱共 8 个字（4 天干 + 4 地支）。
2. 天干：直接按其五行计入。
3. 地支：按**藏干**计入（数据见 `01-数据资料/天干地支与八字/dizhi.json`），本气计 1，中气/余气计 0.5（或按流派简化各计 1）。
   - 例：寅 = 甲木(1) + 丙火(0.5) + 戊土(0.5)；子 = 癸水(1)。
4. 汇总得到五行分布（金木水火土各多少），作为强弱判断的原始输入。

## 二、日主确定

- **日主 = 日柱天干**（如日柱丙申，则日主为丙火）。
- 后续所有"身强/身弱"判断都以日主为参照。

## 三、日主强弱判断规则（关键）

综合四方面打分，不能只看一个维度：

| 维度 | 判断 | 示例 |
|---|---|---|
| **得令**（权重最高） | 日主五行在月令（月支本气）是否当旺 | 日主丙火生于巳/午月 → 得令 |
| **得地** | 日支、时支、年支是否有本五行（尤其长生/禄旺位） | 丙火日主地支见巳/午/未 |
| **得势** | 天干中是否有同类比肩/劫财帮扶 | 天干再见丙/丁 |
| **得助** | 是否有生我的印星（如丙火日主见木） | 天干见甲/乙，地支藏木 |

- **身强**：得令 + 得地/得势/得助任一项以上；或得令且多得帮扶。
- **身弱**：失令（月令克泄耗日主），且帮扶少。
- **中和**：难分强弱，趋向"通关调候"，补缺失五行即可（此时才接近"缺啥补啥"）。

## 四、喜用神确定规则

| 日主状态 | 喜用方向 | 逻辑 |
|---|---|---|
| **身强** | 克、泄、耗日主的五行（官杀/食伤/财星） | 让过旺的日主得到制衡 |
| **身弱** | 生、扶日主的五行（印星/比劫） | 让衰弱的日主得到生扶 |
| **中和** | 视调候（寒暖燥湿）与全局流通 | 兼顾平衡与流通 |

对应到五行操作（以日主为例）：
- 身强：喜「克我者、我生者、我克者」的五行
- 身弱：喜「生我者、同我者」的五行
- 举例：日主丙火身强 → 喜土（我生）、金（我克）、水（克我）；身弱 → 喜木（生我）、火（同我）。

## 五、五行生克关系（基础表）

- **相生**：木→火→土→金→水→木
  - 金生水、水生木、木生火、火生土、土生金
- **相克**：木→土→水→火→金→木
  - 金克木、木克土、土克水、水克火、火克金
- 数据文件：`01-数据资料/三才五格配置表/sancai_125.json` 的 meta 中含生克表。

## 六、取名的五行匹配逻辑

1. 计算候选字五行（来自汉字字库 `wuxing` 字段）。
2. 字五行 ∈ 喜用神五行 → 加分（**核心补益**）。
3. 字五行 ∈ 忌神五行（克泄耗过甚或再帮身）→ 减分/排除。
4. 五行**补益匹配度**打分规则详见 `06-候选名字评分规则.md`。

## 七、注意事项

- **多字整体评估**：补益看名字整体（姓+名）对八字的平衡作用，不是逐字硬凑。
- **不能五行齐全即好**：均衡未必是目的，喜用神方向才是目的。
- **调候优先**：寒冬生人（亥子丑月）喜火暖局，盛夏生人（巳午未月）喜水润局，可作调候加分项。
- 若用户不提供出生时间，则无法排全四柱，可退回"生肖 + 字义"模式，并明确提示限制。

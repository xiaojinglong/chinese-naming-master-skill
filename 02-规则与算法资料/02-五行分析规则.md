# 02 五行分析规则

> 用途：分析八字五行分布 → 判断日主强弱 → 确定喜用神 → 指导取名补益。
> **核心原则：不是简单的"缺啥补啥"，而是以日主强弱与喜用神为准。**

## 一、五行统计（含地支藏干）

1. 八字四柱共 8 个字（4 天干 + 4 地支）。
2. 天干：直接按其五行计入。
3. 地支：按**藏干**计入（数据见 `01-数据资料/天干地支与八字/dizhi.json`），本气计 1，中气/余气计 0.5（或按流派简化各计 1）。
   - 例：寅 = 甲木(1) + 丙火(0.5) + 戊土(0.5)；子 = 癸水(1)。
4. 汇总得到五行分布（金木水火土各多少），作为强弱判断的原始输入。

## 二、日主确定

- **日主 = 日柱天干**（如日柱丙申，则日主为丙火）。
- 后续所有"身强/身弱"判断都以日主为参照。

## 三、日主强弱判断规则（关键）

综合四方面打分，不能只看一个维度：

| 维度 | 判断 | 示例 |
|---|---|---|
| **得令**（权重最高） | 日主五行在月令（月支本气）是否当旺 | 日主丙火生于巳/午月 → 得令 |
| **得地** | 日支、时支、年支是否有本五行（尤其长生/禄旺位） | 丙火日主地支见巳/午/未 |
| **得势** | 天干中是否有同类比肩/劫财帮扶 | 天干再见丙/丁 |
| **得助** | 是否有生我的印星（如丙火日主见木） | 天干见甲/乙，地支藏木 |

- **身强**：得令 + 得地/得势/得助任一项以上；或得令且多得帮扶。
- **身弱**：失令（月令克泄耗日主），且帮扶少。
- **中和**：难分强弱，趋向"通关调候"，补缺失五行即可（此时才接近"缺啥补啥"）。

## 四、喜用神确定规则

| 日主状态 | 喜用方向 | 逻辑 |
|---|---|---|
| **身强** | 克、泄、耗日主的五行（官杀/食伤/财星） | 让过旺的日主得到制衡 |
| **身弱** | 生、扶日主的五行（印星/比劫） | 让衰弱的日主得到生扶 |
| **中和** | 视调候（寒暖燥湿）与全局流通 | 兼顾平衡与流通 |

对应到五行操作（以日主为例）：
- 身强：喜「克我者、我生者、我克者」的五行
- 身弱：喜「生我者、同我者」的五行
- 举例：日主丙火身强 → 喜土（我生）、金（我克）、水（克我）；身弱 → 喜木（生我）、火（同我）。

## 五、五行生克关系（基础表）

- **相生**：木→火→土→金→水→木
  - 金生水、水生木、木生火、火生土、土生金
- **相克**：木→土→水→火→金→木
  - 金克木、木克土、土克水、水克火、火克金
- 数据文件：`01-数据资料/三才五格配置表/sancai_125.json` 的 meta 中含生克表。

## 六、取名的五行匹配逻辑

1. 计算候选字五行（来自汉字字库 `wuxing` 字段）。
2. 字五行 ∈ 喜用神五行 → 加分（**核心补益**）。
3. 字五行 ∈ 忌神五行（克泄耗过甚或再帮身）→ 减分/排除。
4. 五行**补益匹配度**打分规则详见 `06-候选名字评分规则.md`。

## 七、注意事项

- **多字整体评估**：补益看名字整体（姓+名）对八字的平衡作用，不是逐字硬凑。
- **不能五行齐全即好**：均衡未必是目的，喜用神方向才是目的。
- **调候优先**：寒冬生人（亥子丑月）喜火暖局，盛夏生人（巳午未月）喜水润局，可作调候加分项。
- 若用户不提供出生时间，则无法排全四柱，可退回"生肖 + 字义"模式，并明确提示限制。

## 八、十二长生旺衰（进阶判断）

> 来源：《渊海子平》论长生、《子平真诠》论用神、《滴天髓阐微》天干论

十二长生是判断日主及各天干在地支上旺衰程度的精细工具，比仅看"五行相同"更精确。

### 8.1 十二长生顺序

**长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养**

| 阶段 | 旺衰系数 | 含义 | 取名提示 |
|------|---------|------|---------|
| 长生 | 0.8 | 万物初生，充满生机 | 吉位，适合取名用字 |
| 沐浴 | 0.4 | 初生脆弱，桃花之位 | 感情丰富但不稳定 |
| 冠带 | 0.6 | 渐趋成熟，穿衣戴冠 | 成长期，学业进取 |
| 临官 | 0.9 | 出仕做官，能力展现 | **禄位**，事业有成 |
| 帝旺 | 1.0 | 鼎盛极旺 | 最强旺位，过旺需防物极必反 |
| 衰 | 0.5 | 由盛转衰 | 守成期，稳健保守 |
| 病 | 0.3 | 衰病无力 | 力弱需扶，取名宜补益 |
| 死 | 0.1 | 气绝无生机 | 极弱，取名必须大补 |
| 墓 | 0.4 | 收藏入库 | 蓄积力量，有库藏之象 |
| 绝 | 0.05 | 气已断绝 | 最弱，需从零开始 |
| 胎 | 0.3 | 受胎孕育 | 潜力待发 |
| 养 | 0.5 | 养育成长 | 滋养期，稳步发展 |

### 8.4 长生旺衰在取名中的应用

1. **日主坐长生/临官/帝旺**：日主得力，身偏强，取名宜泄耗（食伤/财星方向）
2. **日主坐死/绝/病**：日主失力，身偏弱，取名宜生扶（印星/比劫方向）
3. **日主坐墓**：有收藏之象，需看全局判断是否有利
4. **年柱/时柱长生**：可作辅助加分项

## 九、调候用神深化

> 来源：《穷通宝鉴》核心理念

调候是八字取名中常被忽视但极为重要的维度。核心思想：**寒暖燥湿影响命局平衡，取名用字可作调候补益。**

### 9.1 调候判断规则

| 月令 | 气候特征 | 调候需求 | 取名用字五行 |
|------|---------|---------|-------------|
| 寅卯月（春） | 木旺，气候渐暖 | 火暖局（阳暖）或水润局（阴润） | 火/水 |
| 巳午月（夏） | 火旺，炎热干燥 | **水润局**为第一要务 | 水 |
| 申酉月（秋） | 金旺，气候渐凉 | 火暖金（使金有用）或水润局 | 火/水 |
| 亥子月（冬） | 水旺，寒冷 | **火暖局**为第一要务 | 火 |
| 辰戌丑未月（四季土月） | 土旺 | 看燥湿：辰丑湿土喜火，未戌燥土喜水 | 火/水 |

### 9.3 调候在取名中的权重

- 调候用神与喜用神**一致**时：双重确认，取名方向明确
- 调候用神与喜用神**矛盾**时：以喜用神为主，调候为辅（调候加分但不主导）
- **寒冬/盛夏**出生者：调候权重提升，可作取名首要参考

## 十、格局分类概要

> 来源：《子平真诠》论格局、《滴天髓阐微》论体用

格局是八字分析的高级框架，决定取名的整体策略方向。

### 10.1 正格（八正格）

以月令藏干透出之十神定格：

| 格局 | 月令透出 | 特点 | 取名策略 |
|------|---------|------|---------|
| 正官格 | 正官透出 | 正统守规矩 | 喜财生官、印护官；取名用财/印五行 |
| 七杀格 | 七杀透出 | 有魄力有压力 | 喜食神制杀或印星化杀；取名用食神/印五行 |
| 正财格 | 正财透出 | 务实稳健 | 喜官星护财；取名用官星五行 |
| 偏财格 | 偏财透出 | 人缘好 | 喜食伤生财；取名用食伤五行 |
| 正印格 | 正印透出 | 有学问有贵人 | 喜官星生印；取名用官星五行 |
| 偏印格 | 偏印透出 | 多才多艺 | 需财星制枭；取名用财星五行 |
| 食神格 | 食神透出 | 才华温和 | 喜财星泄食；取名用财星五行 |
| 伤官格 | 伤官透出 | 才华横溢 | 需配印星或官星；取名用印/官五行 |

### 10.2 特殊格局（从格）

当日主极弱或极强，不能按正格分析时，取名策略**相反**：

| 格局 | 条件 | 取名策略 |
|------|------|---------|
| 从强格 | 满盘印比，日主极强 | 顺其势，用印比五行 |
| 从弱格（从杀/从财/从儿） | 满盘克泄耗，日主极弱 | 顺其势，用克泄耗五行 |
| 专旺格 | 某一五行独旺 | 顺其旺势，用该五行或生该五行 |

### 10.3 格局在取名中的优先级

```
调候 > 格局用神 > 喜用神 > 五行平衡
```

- 优先满足调候（寒暖燥湿）
- 其次满足格局所需之十神
- 再次满足日主强弱的喜用神
- 最后考虑五行整体平衡

> **取名提示**：格局分析需专业命理知识，系统可作为高级选项提供。普通用户以"日主强弱 → 喜用神 → 五行补益"为主流程即可。

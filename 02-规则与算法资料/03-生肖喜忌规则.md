# 03 生肖喜忌规则

> 用途：根据出生年份对应的生肖，筛选名字用字的偏旁部首（喜用偏旁加分、忌用偏旁排除）。
> **口径声明**：生肖喜忌属于传统民俗，各版本（《三命通会》生肖相冲合、坊间取名资料）存在差异，本表为通行版本，生产环境可按目标用户群体选择口径并注明。

## 一、判断依据

1. 出生年份 → 生肖（数据见 `01-数据资料/天干地支与八字/shengxiao.json`；注意以**立春**为界）。
2. 生肖 → 对应地支（子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪）。
3. 地支 → 喜用偏旁 / 忌用偏旁（结构化数据见 `03-生肖喜忌偏旁表.json`）。
4. 候选字部首（汉字字库 `radical` 字段）→ 匹配喜忌。

## 二、核心逻辑

- **喜用偏旁**：与该生肖的生活习性、栖息环境、天敌食物、三合六合相关的字根。
  - 例：鼠（子）喜「宀」（洞穴栖息）、「米/豆」（食物）、「王」（鼠为生肖之首）、「艹」（草食）。
- **忌用偏旁**：与生肖**相冲/相刑/相害**的地支字形，以及天敌字形。
  - 例：鼠（子）忌「午/马」（子午相冲）、「羊/未」（子未相害）相关字形。

## 四、实现要点

1. 偏旁匹配：用汉字字库的 `radical` 字段做**前缀/包含匹配**（如「氵」匹配部首为氵的字）。
2. 相冲关系表（地支六冲）：子午、丑未、寅申、卯酉、辰戌、巳亥 → 忌用对冲生肖相关字形。
3. 相害关系表（地支六害）：子未、丑午、寅巳、卯辰、申亥、酉戌 → 忌用相害生肖相关字形。
4. 三合（申子辰、寅午戌、巳酉丑、亥卯未）与六合（子丑、寅亥、卯戌、辰酉、巳申、午未）→ 可作喜用加分参考。
5. 生肖喜忌在评分中为**加分/减分项**，不单独一票否决（除非用户明确要求必须避开）。

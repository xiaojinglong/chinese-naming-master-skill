# 04 音韵筛选规则

> 用途：让名字**读起来好听、叫得响亮**。包含声调搭配、尾字声调、谐音排查、声母韵母检查四部分。

## 一、声调搭配规则

1. **相邻字声调尽量不同**：避免连续同调导致平淡（如「张章章」三连阴平），提倡"平仄交替、抑扬顿挫"。
2. **避免全平或全仄**：全平（如「孙思孙」）平淡无起伏；全仄（如「顾慕岳」）拗口生硬。
3. **声调变化度打分**：相邻字声调不同 +1 分，相同 −1 分；整体按"变化次数/总相邻数"评估。
4. 参考理想模式：二声+四声（扬抑）、三声+二声（抑扬）、一声+三声等组合多属流畅。

## 二、尾字声调规则

- **最后一个字优先一声或二声**（平声），收音响亮、尾音上扬，呼叫时传得远。
- 三声（上声）结尾：收尾低沉、易拖沓，但结合姓氏平仄有时也不错（如「马雨」类叠仄例外需听感判断）。
- 四声（去声）结尾：干脆有力，但单字名偏"断"，双字名可用（如「顾嘉岳」）。
- 打分建议：尾字平声（1/2 声）+2，仄声 +0~1。

## 三、谐音排查（必做项）

| 类型 | 说明 | 例 |
|---|---|---|
| 不雅谐音 | 连读成贬义词 | 「史珍香」「范统」 |
| 歧义谐音 | 连读成其他常见词 | 「杨伟」（谐"阳痿"） |
| 称谓谐音 | 连读像称呼/绰号 | 「朱子」→"猪子" |
| 方言谐音 | 不同方言下变义 | 粤语/吴语/闽语同形异音 |
| 英文谐音 | 对外场合的洋名歧义 | 「Bai Shi」等 |

**排查方法**：
1. 全名（姓+名）连读 → 与常用词库比对；
2. 名单独连读 → 与贬义/歧义词库比对；
3. 姓名首字母缩写（英文）检查；
4. 维护一个"谐音黑名单词库"，持续扩充（姓氏×高频词的组合风险表尤其重要，如「吴」+「德」→"无德"）。

## 四、声母韵母规则

1. **避免相邻字声母相同**：如「李玲」声母均 l，读起来黏连（绕口）；错开则清晰。
2. **避免相邻字韵母相同或相近**：如「王芳」韵母 an/ang 相近尚可，但「唐芳」ang+ang 叠韵过重。
3. **特别避免声母韵母双同**（叠字叠韵）：「张璋」类双音字名，除非刻意（叠名如"圆圆"）否则扣分。
4. 加分项：声母开口度变化（b/p/m 与 g/k/h 交替）使发音有层次。

## 五、综合打分模型（建议）

```
音韵流畅度得分 = 声调变化分(40%) + 尾字声调分(20%) + 声母错开分(20%) + 韵母错开分(20%) − 谐音重罚
```
- 谐音为**一票否决级**：命中不雅/歧义谐音直接淘汰（或给极低分），不参与排序。

## 六、数据与实现

- 拼音数据：汉字字库 `pinyin` 字段（带声调），程序拆出声母/韵母/声调。
- **声母韵母表**：`04-声母韵母表.json`（23 声母 + 39 韵母，含发音部位/呼口分类），用于判断"相邻字声母相同、韵母相近（韵腹相同）、发音部位交替"。
- **谐音黑名单词库**：`04-谐音黑名单词库.json`（不雅词/歧义词/姓氏×名组合风险表/首字母缩写黑名单/方言英文备注），音韵硬过滤直接读取。
- 谐音词库为初始版，生产环境建议引入开源"姓名谐音词库"项目数据 + 自建姓氏×名组合黑名单（持续运营更新）。

# 05 字形筛选规则

> 用途：让名字**写起来好看、结构平衡**。包含笔画繁简搭配、生僻字排除、字形结构三部分。

## 一、笔画繁简搭配规则

1. **相邻字笔画数不宜悬殊过大**：避免「一笔」配「三十笔」（如「丁鑫」视觉失衡，且书写困难）。
2. **总体笔画适中**：单字建议 4–18 画（康熙笔画）；姓名总笔画建议 20–40 画之间为宜。
3. **搭配建议**：笔画像"山峰起伏"而非"一字平"，如 8+12、10+14 类组合观感较佳。
4. 计算方式：用汉字字库 `strokes_kangxi` 字段；`笔画平衡度 = 1 − (最大差 / 最大笔画)`。

## 二、生僻字与难写字排除

| 类别 | 判定 | 处理 |
|---|---|---|
| 生僻字 | 不在《通用规范汉字表》一级字（3500 常用字） | 默认排除，除非用户明确要求 |
| 难写字 | 笔画 > 20 画或结构复杂（如「龘」） | 扣分/排除 |
| 易错字 | 多音多义易读错（如「茜 xī/qiàn」「祎」） | 备注读音，谨慎推荐 |
| 异体字 | 写法不统一（如「峯/峰」） | 统一用规范简体+繁体对照 |

- 实现：字库已内置 `rare_flag`（生僻标记）、`difficult_flag`（难写标记，简体>20画）字段（见 `01-数据资料/汉字字库/hanzi_common.json` 与 `hanzi_schema.json`）。
- **用户可配置**：如家族字辈必须用某字（即使生僻），则跳过此项。

## 三、字形结构规则

1. **结构平衡**：左右结构 ↔ 上下结构搭配，避免全部同一结构（如「林林林」全左右结构呆板）。
2. **视觉重心**：名字整体观感"上紧下松"或"左右均衡"为宜。
3. **偏旁避免重复**：相邻字部首相同易单调（如「琳琳」）；完全叠字名（「明明」）除非刻意。
4. 繁体字形检查：简体名转繁体后若出现笔画暴涨（如「云飞」→「雲飛」21 画），需重新评估平衡。

## 四、字形打分模型（建议）

```
字形美观度 = 笔画平衡度(40%) + 结构多样性(30%) + 书写难度(30%) − 生僻重罚
```

## 五、与五格计算的关系

- 字形筛选用**视觉维度**（简体/繁体均可），五格计算用**康熙笔画**（繁体），两者分工不同，勿混淆。
- 简体好看 ≠ 繁体五格好，反之亦然；报告需同时给出简繁两套笔画信息。

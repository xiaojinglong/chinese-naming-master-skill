# 06 候选名字评分规则

> 用途：对候选名字按多维加权打分，输出**综合评分与排序**，供用户选择。

## 一、评分维度（对应 ziliao.txt 的七个维度）

| # | 维度 | 说明 | 数据来源 |
|---|---|---|---|
| 1 | 五行补益匹配度 | 名字五行对八字喜用神的补益程度 | 八字分析 + 字库 wuxing |
| 2 | 三才配置吉凶 | 天/人/地三格五行组合吉凶 | sancai_125.json |
| 3 | 五格数理吉凶 | 五格笔画数理吉凶（重点人格/总格） | wuge_1to81.json |
| 4 | 音韵流畅度 | 声调、尾字、声母韵母、谐音 | 拼音数据 + 谐音词库 |
| 5 | 字形美观度 | 笔画平衡、结构多样、书写难度 | 字库笔画 + 结构 |
| 6 | 寓意深度 | 字义、经典出处、整体意境 | 字库释义 + 文学素材库 + 成语典故库 + 诗词意象库 |
| 7 | 生肖契合度 | 用字偏旁与生肖喜忌匹配 | 生肖喜忌偏旁表 |

## 二、默认权重（可在 06-评分权重配置.json 调整）

| 维度 | 默认权重 | 说明 |
|---|---|---|
| 五行补益匹配度 | 25% | 取名核心目的，权重最高 |
| 五格数理吉凶 | 15% | 人格、总格重点 |
| 音韵流畅度 | 15% | 好听是刚需 |
| 寓意深度 | 15% | 文化底蕴 |
| 三才配置吉凶 | 10% | 辅助 |
| 字形美观度 | 10% | 辅助 |
| 生肖契合度 | 10% | 民俗偏好 |

合计 100%。

## 三、各维度打分方法（0–100 分制）

1. **五行补益匹配度**
   - 名中 1 个字五行 = 喜用神 → +50；= 调候用神 → +30；= 忌神 → −50。
   - 两个字综合：双字都补益 100 分，单字补益 60 分，无补益 30 分，克泄喜用 0 分。
2. **三才配置吉凶**：大吉 100 / 吉 85 / 半吉 65 / 半凶 40 / 凶 20。
3. **五格数理吉凶**：人格 + 总格为主（各 40%），天格/地格/外格各 20%；吉 100 / 半吉 60 / 凶 20。
4. **音韵流畅度**：按 04 文档的模型（声调变化 40% + 尾字 20% + 声母 20% + 韵母 20%），谐音命中直接淘汰或记 0 分。
5. **字形美观度**：按 05 文档的模型（笔画平衡 40% + 结构 30% + 书写难度 30%）。
6. **寓意深度**：有经典出处 +50（出处来源：`01-数据资料/经典文学素材库/` 与 `03-文化资料/成语典故库.json`、`诗词意象库.json`）；字义正面且有文化意象 +30；字义中性 +15；歧义/负面 −50。
7. **生肖契合度**：全字命中喜用偏旁 100；单字命中 60；命中忌用偏旁 0 分或排除。

## 四、综合评分公式

```
综合分 = Σ(维度得分 × 维度权重)
```

## 五、排序与输出规则

1. **硬性过滤（先过滤再评分）**：
   - 谐音不雅/歧义；
   - 与长辈/近亲重名（用户提供忌用字时）；
   - 字五行严重克泄喜用神；
   - 命中用户明确忌用的字。
2. **软性过滤**：生僻字、笔画过重 → 大幅扣分。
3. 最终输出 Top N（建议 5–10 个），按综合分降序。
4. 报告中每个名字必须附各维度得分明细（对应 04-输出与交互资料/02-输出报告模板.md）。

## 六、权重调整建议

- 用户更看重"文化"（文艺青年/古风偏好）→ 提高"寓意深度"。
- 用户明确要求"宝宝八字要紧" → 提高"五行补益"。
- 用户只要好听的现代名 → 提高"音韵"，降低"三才/数理"（甚至可关闭传统维度）。
- 权重配置支持从 JSON 读取，Skill 可按用户偏好动态覆盖。

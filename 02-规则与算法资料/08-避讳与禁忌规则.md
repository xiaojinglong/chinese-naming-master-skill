# 08 避讳与禁忌规则

> 来源：《左传》"五类六不" + 巨天中《吉名如意》十一忌 + 传统避讳制度
> 知识库精读：`06-取名知识库/01-先秦经典/11-左传.md`（五类六不）、`06-取名知识库/03-现代参考书/26-巨天中.md`（11忌）

## 一、左传"五类六不"（取名规则源头）

### 五类（命名意图分类）

| 类别 | 含义 | 示例 |
|------|------|------|
| 信 | 以出生时天象/特征为信 | 郑庄公"寤生"（难产） |
| 义 | 以祥瑞/德义为名 | 周文王"昌" |
| 象 | 以相貌/相似之物为名 | 孔子名"丘"（头似尼丘山） |
| 假 | 借物/借字为名 | 借草木禽兽之名 |
| 类 | 以类同事物为名 | 以同类事物寄托 |

### 六不（命名禁忌）

1. **不以国**——国名不可为名（讳国号）
2. **不以官**——官名不可为名（讳官职）
3. **不以山川**——山川名不可为名
4. **不以隐疾**——疾病名不可为名
5. **不以畜牲**——牲畜名不可为名
6. **不以器币**——礼器钱币名不可为名

> 原则：**以名生信，信以守物**——名字承载信义，不可轻亵。

## 二、巨天中"十一忌"（现代取名禁忌）

| 序 | 禁忌 | 说明 |
|----|------|------|
| 1 | 忌粗俗字 | 避免低俗不雅字 |
| 2 | 忌过头字 | 避免过于夸大（如"天帝""万岁"） |
| 3 | 忌绕口令 | 避免声母/韵母连续相同导致拗口 |
| 4 | 忌繁难字 | 避免笔画过多或生僻字 |
| 5 | 忌拼盘字 | 避免多种风格混搭不协调 |
| 6 | 忌消极字 | 避免悲观消极含义 |
| 7 | 忌浅薄字 | 避免无文化底蕴 |
| 8 | 忌多音字 | 避免多音字导致歧义 |
| 9 | 忌男女不分 | 避免男名女用或女名男用 |
| 10 | 忌丑恶字 | 避免丑陋恐怖含义 |
| 11 | 忌嫌疑字 | 避免有不雅谐音或联想 |

## 三、传统避讳制度

### 避讳三制

| 制度 | 说明 | 示例 |
|------|------|------|
| 国讳 | 避帝王及先祖名讳 | 清代避"玄烨"→改"玄"为"元" |
| 家讳 | 避家族长辈名讳 | 王安石父名"益"→不写"益"字 |
| 圣人讳 | 避孔孟先圣名讳 | 避"丘"→加阝为"邱" |

### 避讳方法

1. **改字**：以同义/近义字替代（"世民"→"代宗"）
2. **缺笔**：少写一笔（"丘"→少写一竖）
3. **空字**：以"讳"或空格替代

### Skill 实现要点

- 收集用户家族长辈名讳（用户信息收集模板已有 `forbidden_chars` 字段）
- 与谐音黑名单词库（`04-谐音黑名单词库.json`）配合做硬过滤
- 多音字检查：从字库 `pinyin` 字段判断是否多音

## 四、与音韵/字形筛选的配合

| 禁忌类型 | 对应规则文件 |
|---------|------------|
| 忌绕口令 | `04-音韵筛选规则.md` + `04-声母韵母表.json` |
| 忌繁难字 | `05-字形筛选规则.md` + 字库 `difficult_flag`/`rare_flag` |
| 忌多音字 | 字库 `pinyin` 字段多值检测 |
| 忌丑恶/嫌疑 | `04-谐音黑名单词库.json` 不雅词 + 歧义词 |
| 忌男女不分 | 字库 `gender_hint` 字段 |
| 忌粗俗/消极 | 谐音黑名单 + 字义语义判断 |

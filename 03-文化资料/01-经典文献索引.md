## 三、素材字段 → 报告输出映射

文学素材库每条 `item` 直接服务于报告中的「字义原理」段落：

```
字义原理 = 现代释义（字库 meaning）
          + 经典出处（素材 origin + quote）
          + 取名寓意（素材 meaning / usage）
```

例：「清扬」→ 《诗经·郑风·野有蔓草》"有美一人，清扬婉兮" → 眉目清秀、神采飞扬。

## 四、出处规范（防止"穿凿附会"）

1. **必须真实**：每条出处需能查到原句，禁止编造"出自某诗"。
2. **篇名准确**：写全「书名·篇名」（如《诗经·郑风·野有蔓草》）。
3. **断章取义标注**：若原句语境与取名寓意不同（如"忧心忡忡"类），宁可不用。
4. **版本**：以中华书局/上海古籍通行本为准。
5. **人工校对流程**：素材入库前由人核对一次，Skill 输出时不改原文。

## 五、扩充建议

- 按"篇目级"收录：每篇经典取其可取名语句 3-10 句。
- 建立「出处 → 字/词」倒排索引，加速反查。
- 对高频取名字（如「清」「安」「之」「子」）建立"出处清单"，输出时优先引用。

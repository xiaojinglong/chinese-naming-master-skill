## 一、姓名学的历史渊源

### 1. 先秦：名与字的起源
- 《礼记·内则》记载生子三月而取名；男子二十冠而字，女子许嫁笄而字。
- 名以正体，字以表德；"字"是对"名"的解释与补充（如屈原：名平，字原）。
- 周代已有"五则"取法（信、义、象、假、类），忌讳以国名、官名、山川、隐疾、畜牲命名。

### 2. 汉代：五行思想渗入
- 阴阳五行学说兴盛，东汉《白虎通义》已有"五行命名"记载。
- 按"五行相生"排辈（如木生火，父名木旁字、子名火旁字）的**五行字辈**传统萌芽。

### 3. 唐宋：避讳与字辈谱
- 避讳制度严格（避皇帝名、尊长名）。
- 家族**字辈谱/昭穆**成熟：同辈共用一个字（如"孔令"辈），形成"字辈诗"（如孔氏"希言公彦承，宏闻贞尚胤"）。

### 4. 明清：八字五格理论的成型
- 子平八字理论成熟，取名与命理深度结合（缺啥补啥的民间俗信在此时普及）。
- 清初《三才五格剖象法》相关理论（源自日本熊崎健翁，民国时期传入中国并流行）开始影响民间。

### 5. 近现代：五格剖象法的流行
- 熊崎健翁（日本）创立"五格剖象法"，民国传入后经中国人改良，成为当代姓名学软件的主流算法。
- 五格：天格/人格/地格/外格/总格 + 三才配置（天/人/地五行），形成当前"五格三才"体系。

## 二、主要流派

| 流派 | 核心 | 特点/争议 |
|---|---|---|
| 五格剖象法 | 笔画数理 + 三才配置 | 最普及，可量化，但笔画归数与吉凶表版本不一 |
| 八字命理派 | 日主强弱 + 喜用神 | 学术根基在子平术，最被命理界认可 |
| 生肖派 | 生肖喜忌偏旁 | 民俗性最强，版本差异大 |
| 音韵派 | 声调平仄、谐音 | 语言学基础扎实，公认重要 |
| 字形派 | 笔画结构、平衡美观 | 视觉审美，主观性较强 |
| 字义派 | 寓意、出处、文化 | 文化价值高，是"好名字"的普遍共识 |

> **实务建议**：综合流派取交集——字义好（共识）+ 音韵好（共识）+ 五行合（八字）+ 数理吉（五格）+ 生肖合（民俗），五者都满足的名字即为优质候选。

## 三、各朝代取名习俗演变

| 朝代 | 习俗特点 | 典型例名 |
|---|---|---|
| 先秦 | 单名为主，重"义"；五则取法 | 孔丘、孟轲、屈原 |
| 秦汉 | 单名极盛（王莽改制推动）；谶纬影响 | 刘邦、项羽、卫青 |
| 魏晋南北朝 | 玄学、佛道影响；"之"字入名流行 | 王羲之、顾恺之 |
| 唐 | 排行入名（"十二郎"）；双名渐多 | 李白（排行十二）、杜甫 |
| 宋 | 理学影响，重德性；字辈谱成熟 | 朱熹、苏轼、欧阳修 |
| 元 | 蒙古文化影响，粗犷名多 | （民间名多样化） |
| 明清 | 五行字辈、八字补缺流行 | 朱由检（五行辈）、爱新觉罗氏字辈 |
| 近现代 | 五格剖象法 + 时代意象（建国/卫东等） | 时代特征鲜明 |
| 当代 | 多元化：古风、诗词、个性、复姓复兴 | 修远、清扬、知夏等 |

## 四、姓名文化中的常用概念

| 概念 | 说明 |
|---|---|
| 名与字 | 名是出生所取，字是成年所取，互为表里（表字） |
| 号 | 文人自取的别号（如东坡居士），不入户口 |
| 避讳 | 对君主/尊长名不得直书直呼；"避讳改字"造成古籍异文 |
| 字辈 | 家族同辈共享的排辈字，常组成五言/七言字辈诗 |
| 五行补缺 | 民间"缺啥补啥"的简化俗信；专业上应看喜用神 |
| 三才 | 天格、人格、地格的五行组合（天人地三才） |
| 五格 | 天格/人格/地格/外格/总格 |
| 生肖喜忌 | 按生肖挑选偏旁（民俗） |
| 声韵格律 | 名字读感的平仄、声母韵母搭配 |

# 01 用户信息收集模板

> 用途：Skill 启动时向用户收集取名必需信息。对应 ziliao.txt「四、输出与交互资料 / 1. 用户信息收集模板」。
> 结构化 Schema 见 `01-user-input-schema.json`。

## 一、必填信息

| 字段 | 说明 | 示例 | 缺省处理 |
|---|---|---|---|
| 姓氏 | 单姓/复姓均可 | 李 / 欧阳 | 必填 |
| 性别 | 男 / 女 | 男 | 必填（影响候选字倾向） |

## 二、建议收集信息（影响取名质量）

| 字段 | 说明 | 示例 | 缺省处理 |
|---|---|---|---|
| 出生日期 | 公历，年/月/日 | 2026-08-26 | 缺省→不做八字分析，降级生肖模式 |
| 出生时间 | 精确到小时/分钟（可选） | 10:30 | 缺省→按子时假设并标注，或仅用年月日 |
| 出生地 | 可选（部分流派看真太阳时） | 北京 | 缺省→按北京时间 |
| 忌用字 | 家族长辈用字/不喜欢的字 | "伟、强" | 缺省→无 |
| 风格偏好 | 文雅/大气/古风/现代/吉祥等 | 文雅古风 | 缺省→均衡 |
| 名字字数 | 2字名 / 3字名（含姓） | 2字名 | 缺省→两种都出 |
| 期望五行 | 可选（若用户有明确需求） | 补木火 | 缺省→按八字喜用神 |
| 特殊要求 | 家族字辈、纪念字等 | 字辈"承" | 缺省→无 |

## 三、对话式采集话术（一次一问，避免问卷感）

```
1. 您好！给宝宝取名，先告诉我宝宝姓什么？（单姓或复姓都可以）
2. 是男孩还是女孩呢？
3. 宝宝的出生日期是？（公历，例如 2026年8月26日）
4. 能提供几点几分出生吗？（不记得也没关系，可以按默认时辰排盘）
5. 有没有家里长辈已经在用的字、或者您希望避开的字？
6. 您更偏好哪种风格？例如：文雅古风 / 大气庄重 / 现代好听 / 吉祥祝福 / 清新自然
7. 想要两字名（如：李x）还是三字名（如：李x x）？
```

## 四、最小可用输入（降级方案）

当用户只提供「姓氏 + 性别」时，仍可运行：
- 模式：**生肖 + 字义 + 音韵 + 五格**（无八字）
- 候选生成：文学素材库 + 高频吉字 + 生肖喜忌
- 报告标注：*未提供出生信息，以下分析不含八字五行补益*。

## 五、输入校验

- 姓氏：必须在姓氏库（单姓 413 / 复姓 53）；不在库则询问繁体写法与笔画。
- 日期：合法公历日期；未来日期提示"出生日期应不晚于今天"。
- 性别：仅接受 男/女。
- 忌用字：转为排除集，生成时硬过滤。
- 风格：映射到候选来源与权重预设（见 06-评分权重配置.json 的 presets）。

# 02 输出报告模板

> 用途：定义每个候选名字的**输出报告结构**，对应 ziliao.txt「四、输出与交互资料 / 2. 输出报告模板」。
> 结构化 Schema 见 `02-output-report-schema.json`。

## 一、报告整体结构

```
📛 取名报告（基于 XX 年 XX 月 XX 日 XX 时 出生 · XX 氏 · 风格：XX）
├── 基础信息回显（八字/生肖/喜用神摘要）
├── 候选名字列表（Top 5-10，综合分降序）
│   └── 每个名字的详细卡片（见下）
└── 附注（口径说明与免责）
```

## 二、单名卡片字段（对应 ziliao.txt 七项要求）

### 1. 基本信息
| 字段 | 说明 | 示例 |
|---|---|---|
| 姓名 | 全名 | 李明轩 |
| 读音 | 全名拼音 | lǐ míng xuān |
| 综合评分 | 0-100 分 + 排名 | 92 分（第 1 名） |

### 2. 字义原理（逐字解释，引用经典出处）
- 每个字的现代释义 + 经典出处（若有）+ 取名寓意。
- 例：明——光明、明亮（《说文》"照也"）；轩——高轩、气宇（《说文》"曲輈藩车"）。

### 3. 五行分析（每个字的五行属性及补益情况）
- 明（火）+ 轩（土）→ 配合喜用神（如日主丙火身弱喜木火 → 明字补火 ✓，轩字耗火 △）。
- 标注：补益 / 平 / 克泄，并给出整体五行匹配评语。

### 4. 五格数理分析（天/人/地/外/总格及吉凶）
| 格 | 计算 | 数理 | 吉凶 |
|---|---|---|---|
| 天格 | 李7+1=8 | 8（八卦之数） | 吉 |
| 人格 | 7+8=15 | 15（福寿之数） | 吉 |
| 地格 | 8+10=18 | 18（铁镜重磨） | 吉 |
| 外格 | 总格−人格+1=… | … | … |
| 总格 | 7+8+10=25 | 25（英俊之数） | 吉 |

### 5. 三才配置（五行组合及吉凶）
- 天格（木）→ 人格（火）→ 地格（土）：木生火、火生土 → **大吉**（查 sancai_125.json）。

### 6. 音韵检查（声调、谐音、声母韵母）
- 声调：lǐ(3) míng(2) xuān(1) → 仄平平，尾字平声收音响亮 ✓。
- 谐音：全名/单名连读检查结果 ✓（无不良谐音）。
- 声母韵母：l/m/x 错开，ing/uan 无叠韵 ✓。

### 7. 创意定位（整体寓意）
- 一句话总结：如「明轩——光明磊落、气宇轩昂，寓意心怀光明、卓然不凡」。
- 可附典故组合说明（素材出处）。

### 8. 综合评分与排序
- 各维度得分明细（七维雷达/表格）+ 综合分 + 排名。
| 维度 | 得分 | 权重 | 加权 |
|---|---|---|---|
| 五行补益 | 85 | 25% | 21.25 |
| … | … | … | … |
| **综合** | | **100%** | **92** |

## 三、输出格式建议

- **对话内**：给 Top 3 简版卡片（名字+评分+一句话寓意+重点提示），引导用户选择。
- **完整报告**：提供 Markdown / HTML 文档，含全部候选的完整卡片。
- **可交互**（可选）：让用户对候选打分、收藏、要求"再来一批"（换字换序）。

## 四、报告措辞规范

1. 传统判定用"参考/寓意"措辞（"数理为吉，属传统参考"）。
2. 每个"吉凶"结论附数据来源（三才表/数理表）。
3. 无八字时明确标注"未排八字，以下为生肖+字义+音韵+五格模式"。
4. 涉及健康/婚姻等敏感解读：统一弱化（姓名学本身不主张此类强断言），仅保留"性格/运势意象"层面的中性表述。

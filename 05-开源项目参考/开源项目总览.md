# 开源项目总览

> 对应 ziliao.txt「五、可参考的开源项目」。以下五个项目均可直接参考其数据结构和实现逻辑。

## 1. chinese-name-craft（八字五行取名工作流）

- **定位**：基于八字五行的完整取名工作流，含 **10 个步骤**。
- **参考价值**：
  - 端到端流程设计（从排盘到输出报告）——对应本库 `02-规则与算法资料/算法总览与数据流.md`。
  - 用户信息收集字段设计——对应 `04-输出与交互资料/01-用户信息收集模板.md`。
  - 输出报告结构——对应 `04-输出与交互资料/02-输出报告模板.md`。
- **借鉴点**：步骤化工作流（Step-based）的提示词工程组织方式。

## 2. James88/qiming（完整字库数据）✅ 已接入

- **定位**：含**完整字库数据**的取名项目。
- **接入状态（2026-08-26）**：已下载完整仓库并归档至 `05-开源项目参考/james88-qiming/`，核心数据已加工进资料库：
  - `gsc_pinyin.csv`（8105 字：笔画/五行/部首/繁体）+ `xinhua.csv`（10238 字康熙笔画）+ `word.json`（14809 字释义）→ 合并为 `01-数据资料/汉字字库/hanzi_full.json`（18,821 字）
  - `Chinese_Names_Corpus_Gender（120W）.txt` → 性别统计 `01-数据资料/性别语料库/性别倾向统计.json`
  - `sancai.txt` → 三才完整表 `01-数据资料/三才五格配置表/sancai_full.json`
  - 加工口径与注意事项见 `james88-qiming/数据接入说明.md`
- **数据文件**（原始）：
  - `xinhua.csv`：新华字典数据（拼音、偏旁、笔画）。
  - `wuxing_dict_fanti.json` / `wuxing_dict_jianti.json`：按**五行 + 笔画**排列的字典（五行数据源）。
  - `word.json`：汉字全量数据。
- **参考价值**：**全量字库（18,821 字）的接入来源**，详见 `01-数据资料/汉字字库/字库扩充指南.md`。

## 3. naming-assistant（诗经楚辞选字 + 八字五行）

- **定位**：从《诗经》《楚辞》选字，结合八字五行的取名助手。
- **参考价值**：
  - 文学素材库的构建思路（出处/原句/寓意字段）——对应本库 `01-数据资料/经典文学素材库/`。
  - 经典选字 + 五行校验的混合策略。
- **借鉴点**：素材 → 候选字 → 五行校验 的流水线。

## 4. chinese-naming-mcp-toolset（专业 MCP 工具集）

- **定位**：专业取名 MCP 工具集，含 **10 个分析工具**。
- **参考价值**：
  - 工具拆分粒度参考（如：排盘工具 / 五行分析工具 / 音韵检查工具 / 五格计算工具 / 生肖检查工具 / 报告生成工具等）。
  - 把"规则文档"实现为"可调用工具"的工程化方式。
- **借鉴点**：MCP Server 的 tool 划分与本库 02-规则文档一一对应。

## 5. baobao-qiming（纯本地 Chrome 插件）

- **定位**：纯本地运行的 Chrome 插件，基于八字五行取名。
- **参考价值**：
  - 轻量本地字库的压缩策略（插件体积受限时的数据取舍）。
  - 前端交互体验（用户输入 → 结果展示的无后端方案）。
- **借鉴点**：浏览器端离线可用性、数据打包方式。

## 选型建议

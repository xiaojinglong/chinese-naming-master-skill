## 三、取名标准工作流（本知识库支撑的七步流程）

```
第1步 需求确认：性别 / 期望气质 / 辈分字 / 生辰 / 家族避讳
        ↓ 依据：11-左传（五类：信义象假类＝五种命名意图）
第2步 规则装载：五宜（好听好讲好写好运好相）+ 十八禁忌
        ↓ 依据：项目资料库《取名规则.txt》
第3步 源典选择：按需求映射典籍（女诗经/男楚辞/文论语/武周易/正孟子…）
        ↓ 依据：本库01-13、29号文件素材表
第4步 字词生成：典籍截取 + 技法生成（借典/离合/谐音/嵌字…）
        ↓ 依据：28-李正明（20算子）+ 17-骈字类编（主题扩词）
第5步 音形义校验：
        音：声调平仄、双声叠韵、方言谐音  → 21-谭汝为
        形：笔画结构、部首重复           → 15-说文 + 18-康熙（笔画）
        义：本义考证、语境核查           → 14-尔雅 + 15-说文
        词组出处验证                     → 16-佩文韵府
第6步 硬性筛查：生僻字过《通用规范汉字表》/ 重名查询 / 家族避讳
第7步 交付呈现：名字＋出处＋篇章大意＋白话释义（可选：配字/号）
        ↓ 格式范本：24-洪澜（四元组词条结构）
```

## 六、维护说明

- 各文件自成一体，可独立增删；新增书籍按"编号-书名-作者.md"格式放入对应目录并更新本目录。
- **04-专题资料**为跨书主题档案，取自原始资料库（取名规则/取名数据/取名数据2）的跨书维度整理＋网络搜索核实，非单一书目；新增专题按"编号-主题.md"格式放入。
- 素材表新条目格式统一为：出处｜原句｜可取名字｜寓意。
- **内容深度分级**：
  - 先秦经典14本＝**精读级**（素材表＋历史案例，内容可靠、覆盖核心名句）
  - 辞书工具书5本＝**工作流级**（定位明确：查义/查韵/查笔画，非逐条素材）
  - 现代参考书10本＝**精读级**（出版档案经核实，章节目录、核心方法论、作者背景、创作史均经网络搜索补深，2026-08-26完成）
  - 跨书专题5个＝**专题级**（从原始资料库跨书维度独立成档，关键事实经网络搜索核实，2026-08-26完成）
- 与项目根目录三份原始资料（取名规则/取名数据/取名数据2）配合使用：本库为"书"与"跨书专题"的维度，资料库为"规则与史"的维度。

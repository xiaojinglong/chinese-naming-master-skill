# 《楚辞》精读笔记

> 知识库 · 先秦经典 02 ｜ 取名四大源流之二："男《楚辞》"

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 中国第一部浪漫主义诗歌总集，以屈原作品为核心 |
| 辑成 | 西汉刘向辑编成集；东汉王逸作《楚辞章句》流传至今 |
| 篇幅 | 以《离骚》《九歌》（11篇）《天问》《九章》（9篇）《远游》《卜居》《渔父》为主，附宋玉《九辩》及汉人拟作 |
| 风格 | 辞藻华丽、想象奇崛、香草美人的象征系统、"兮"字句式 |
| 地位 | 与《诗经》并称"风骚"，中国文学的两大源头之一 |

## 二、结构精读

- **《离骚》**：屈原代表作，自叙身世、修能、遭谗、求索（详见本库 12-离骚 专篇）。
- **《九歌》（11篇）**：屈原据楚地祭祀乐歌改写的人神恋歌，语言清丽缠绵（东皇太一、云中君、湘君、湘夫人、少司命、东君等），是楚辞中最易取名的部分。
- **《天问》**：对天地古今发出172问，气势磅礴，取名价值在气象不在字句。
- **《九章》（9篇）**：涉江、橘颂、哀郢等，多坚贞高洁之志。《橘颂》"秉德无私"尤为取名佳句。
- **《远游》《卜居》《渔父》**：言超脱与守节。朱自清之名出自《卜居》"宁廉洁正直以自清乎"。

## 五、使用要点

1. **"男楚辞"的实质**：楚辞气质浪漫奇崛，意象宏阔（骐骥、云旗、飞廉），适合取有抱负感、有诗意的男名；但其中清丽篇目（九歌、橘颂）同样适合女名（宜修、若英、秋兰），不必拘泥。
2. **香草系统**：楚辞香草（江离、辟芷、秋兰、杜若、木兰）构成一个"芳洁"意象群，命中喜木者可整组选用。
3. **正则／灵均的特殊性**：这两字是《离骚》中屈原自叙的名字美称（"名余曰正则兮"），并非屈原名"平"字"原"本身，但历来被当作最顶级的名字范本——取名者自我命名意识的源头文本。
4. **生僻字警示**：楚辞用字较古（暾、翙、璆、蕙纕），选字需过《通用规范汉字表》关，避免"骐骥"变录入难题。
5. **"兮"字不入名**：句末语气词纯为音节服务，无实义，不取。

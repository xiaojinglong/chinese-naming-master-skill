# 《论语》精读笔记

> 知识库 · 先秦经典 03 ｜ 取名四大源流之三："文《论语》"

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 孔子及其弟子的言行录，儒家第一经典 |
| 时代 | 战国前期成书，辑录春秋末期言行 |
| 篇幅 | 20篇（学而、为政、八佾、里仁、公冶长、雍也、述而、泰伯、子罕、乡党、先进、颜渊、子路、宪问、卫灵公、季氏、阳货、微子、子张、尧曰） |
| 编者 | 孔子弟子及再传弟子 |
| 特点 | 语录体，短句密集，天然适合截取为名 |

## 二、核心内容精读（与取名相关的思想框架）

- **仁**：全书核心，"仁者爱人"。德行系统是论语取名的价值内核。
- **君子人格**：君子 vs 小人的对照贯穿全书，君子词汇（怀德、坦荡、弘毅、不忧不惧）是名字的高频素材带。
- **为学之道**：学而时习、温故知新、敏而好学、不耻下问——适合"学"系名字。
- **中庸克己**：克己复礼、三省吾身、慎言讷言——自省型名字来源。

## 五、使用要点

1. **德行词库**：论语词汇偏德行理智（敏、慎、弘、毅、诚、恕），适合寄托品格期望的"期望式命名"。
2. **双字格言密度高**：论语二字组合（敏行、思齐、弘毅、博文）自带经典背书，且平实易认，生僻字风险为零。
3. **姊妹篇联动**：与《大学》《中庸》《孟子》合称四书，同一概念族（明德、至善、慎思、笃行）跨书出现，可互参。
4. **时代感提示**：论语名字自带书卷气与端庄感；近年流行名（梓涵、子轩）泛滥的背景下，论语系名字反而辨识度更高。
5. **贬义排查**：论语中亦有"巧言令色""无所用心"等贬义语，程序化取材时需带贬义词过滤表。

# 《尚书》精读笔记

> 知识库 · 先秦经典 05 ｜ "政书之祖"，四书五经之"五经"之一

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 上古政令文书、誓诰言辞的汇编，"政书之祖，史书之源" |
| 结构 | 分《虞书》《夏书》《商书》《周书》；今文尚书28篇（汉伏生所传），古文尚书真伪问题复杂（伪古文25篇为晋人伪作，但其中名句已成文化共识） |
| 时代 | 记事上起尧舜，下至东周；最终编定于春秋战国至汉 |
| 语言特点 | "佶屈聱牙"（韩愈语），古奥凝重 |

## 二、与取名的关系

尚书是德治话语的总源头。"德、敬、诚、恭、谦"系统的最早集中表达，适合取端正大气、以德为核的名字。素材密度低于诗经楚辞，但字字有分量。

## 四、历史命名案例

- "俊德"：尧典"克明俊德"是历代"德"系名字的上源。
- "日新"：清华学堂、无数学校校训"日新"系统的源头之一（亦见《大学》引汤之盘铭，两处互见）。
- 民国人物名中"允恭""克让"式名字（排行+德目结构）多溯源于此。
- 陶行知（教育家）：原名文濬，先改"知行"（取王阳明"知行合一"），再改"行知"（强调"行是知之始"）——知行命名的经典故事，上接《说命》"非知之艰，行之惟艰"。

## 五、使用要点

1. **真伪篇目提示**：上表部分句子出自"伪古文尚书"（如大禹谟、旅獒），自清代阎若璩《尚书古文疏证》考证以来学术上判为伪作，但这些语句已融入千年文化传统，作为取名素材完全可用，学术引用时需注明。
2. **语言转换**：尚书词汇过于古奥者（如"翕受敷施"）不直接入名，取其简明者（谦、俊德、好问）。
3. **"德"系核心**：欲取品德期望名，尚书与《论语》《周易》构成三大德目词源，可交叉验证。

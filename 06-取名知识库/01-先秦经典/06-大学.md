# 《大学》精读笔记

> 知识库 · 先秦经典 06 ｜ "初学入德之门"——四书之首

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 儒家修身治国的纲领性文献 |
| 出处 | 原《礼记》第四十二篇；北宋二程表彰，南宋朱熹将其与《论语》《孟子》《中庸》合编"四书"并作《大学章句》 |
| 结构 | 朱熹分"经一章"（孔子之言、曾子述之）＋"传十章"（曾子之意、门人记之），全文约1700余字 |
| 地位 | 四书之首（朱熹定序），元明清科举必读 |

## 二、核心内容精读

**三纲领**：明明德、亲民（一作"新民"）、止于至善——为学与做人的最高目标。
**八条目**：格物 → 致知 → 诚意 → 正心 → 修身 → 齐家 → 治国 → 平天下——由内圣而外王的完整序列。
**修养论**：知止而后有定、慎独（"君子必慎其独也"）、日新（汤之盘铭："苟日新，日日新，又日新"）。

三纲领八条目本身就是一个现成的"名字概念系统"，每个环节都可入名，且相互之间有内在逻辑关联（适合兄弟联名、字辈系统设计）。

## 四、历史命名案例

- **校训系统**：厦门大学校训"自强不息，止于至善"（前半出《周易》后半出《大学》）；东南大学校训"止于至善"。
- **"日新"名**：近代以来以"日新"入名者极多（作家、学者名常见），取自汤盘铭。
- **"明德"名**：历代"明德"系名字（李明德、朱明德等）的直接经典出处。

## 五、使用要点

1. **纲领名气场宏大**：明德、至善、日新等名字端庄大气，但使用极广（尤其"明德"），取名前应做重名评估。
2. **八条目系统命名**：格物、致知、诚意、正心、修身、齐家——六个概念可做兄弟/字辈系统的现成骨架（如兄弟分别名"格致""诚正"）。
3. **引文互见**：《大学》大量引用《诗经》《尚书》原句（"其命维新"引大雅·文王；"如琢如磨"引卫风·淇奥），溯源时注意标注原始出处。
4. **与《中庸》搭配**：两篇同出《礼记》，同被朱熹升格，气质相近（内敛修身），可作为一个语料带使用。

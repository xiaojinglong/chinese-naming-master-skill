# 《中庸》精读笔记

> 知识库 · 先秦经典 07 ｜ "孔门传授心法"——性命之书

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 儒家哲学论文，论述"中庸""中和""诚"的形上体系 |
| 出处 | 原《礼记》第三十一篇，相传子思（孔子之孙）作；朱熹编入四书并作《中庸章句》 |
| 结构 | 朱熹分33章；首章"天命之谓性，率性之谓道，修道之谓教"为总纲 |
| 地位 | 从"礼记之一篇"升格为"四书之一"，宋明理学核心文本 |

## 二、核心内容精读

- **中庸**："喜怒哀乐之未发谓之中，发而皆中节谓之和"——不偏不倚、恰到好处。
- **诚**："诚者，天之道也；诚之者，人之道也"——真实无妄是宇宙法则。
- **博学五步**："博学之，审问之，慎思之，明辨之，笃行之"——为学五环节，名字富矿。
- **三达德**："智、仁、勇三者，天下之达德也"。
- **中和位育**："致中和，天地位焉，万物育焉"——"位育"成为教育学经典概念（潘光旦倡"位育"教育）。

## 五、使用要点

1. **五步名系统**：博学、审问、慎思、明辨、笃行——五个词同源同构，是兄弟联名、双胞胎命名、字辈设计的顶级素材（如长子"慎思"、次子"笃行"）。
2. **诚明／明诚镜像**：一对反向组合，适合兄妹或姐弟对名。
3. **气质内敛**：中庸名字偏沉静自守（居易、敦厚、慎独类），适合期望稳重人格的家庭；与《周易》的刚健系形成互补。
4. **"自卑"陷阱**："登高必自卑"中"自卑"是"从低处开始"之义，古今词义巨变，切勿直接入名。

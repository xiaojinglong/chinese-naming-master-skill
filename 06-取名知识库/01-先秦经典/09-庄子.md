# 《庄子》精读笔记

> 知识库 · 先秦经典 09 ｜ 想象力的巅峰——"逍遥"型名字的源头

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 庄周及后学著作汇编，道家二号经典 |
| 结构 | 33篇：内篇7（庄子自著）、外篇15、杂篇11 |
| 时代 | 战国中期至晚期累积而成 |
| 风格 | "汪洋辟阖，仪态万方"（鲁迅评）；寓言、重言、卮言三位一体 |
| 内篇目录 | 逍遥游、齐物论、养生主、人间世、德充符、大宗师、应帝王 |

## 二、核心内容精读（取名相关的意象系统）

- **逍遥游的物象**：鲲鹏、扶摇、九万里、图南——"大"与"飞"的意象群，志向型男名的顶级素材。
- **齐物论的思辨**：天籁、梦蝶、万物一体——哲学气质名。
- **养生主的技术**：庖丁解牛、游刃有余——"游"字系（游刃、逍遥）。
- **心斋坐忘的功夫**：心斋、坐忘、撄宁、朝彻、见独——内修型名字，气质空灵。
- **成语富矿**：庄子贡献成语数百条（鹏程万里、望洋兴叹、游刃有余、相濡以沫、螳臂当车……），成语取名时可溯源至此。

## 五、使用要点

1. **意象分型使用**：庄子素材分三型——志向型（鲲鹏、扶摇、图南）适合男名期望；空灵型（心斋、坐忘、虚室、天籁）适合气质名；谐趣型（知鱼、秋水、江湖）适合洒脱人格定位。
2. **与《道德经》组队**：老庄常并称，柔美词汇（若水、守静 vs 知白、撄宁）可跨书组合使用。
3. **"相忘"语境**："相忘于江湖"是旷达语，但"相忘"二字单独成名易被理解为"互相遗忘"（负面），需配姓氏谨慎测试。
4. **慎用避世词**：坐忘、撄宁等词境界高远但指向出世，普通家庭取名建议优先逍遥游、秋水等积极意象。

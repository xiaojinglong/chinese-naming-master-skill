# 《孟子》精读笔记

> 知识库 · 先秦经典 29（后补） ｜ "养气"型人格名的第一源典

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 作者 | 孟轲（约前372—前289），战国邹人，孔子之孙孔伋（子思）再传弟子 |
| 体例 | 对话体语录，七篇各分上下：梁惠王、公孙丑、滕文公、离娄、万章、告子、尽心 |
| 地位 | 儒家第二经典，南宋朱熹列入"四书"；元丰年间配享孔庙，称"亚圣" |
| 风格 | 雄辩滔滔、气势磅礴、善用比喻与排比，"若决江河，沛然莫之能御" |
| 与取名的关系 | 不在"女诗经男楚辞文论语武周易"口诀之内，但贡献了中国取名史上生命力最强的一条人格意象——**浩然之气**；其"顶格"句式（大任、兼善、大丈夫）是志向型男名的宝库 |

## 二、结构精读

- **梁惠王（上下）**：孟子见梁惠王、齐宣王，王道仁政总纲。"老吾老以及人之老"的推恩逻辑在此。
- **公孙丑（上下）**：**取名价值最高的一篇**。浩然之气、天时地利人和、以德服人、出类拔萃皆出于此。
- **滕文公（上下）**：性善、五伦（父子有亲、朋友有信）、大丈夫章（富贵不能淫）。
- **离娄（上下）**：修身与诚。"思诚""反求诸己""赤子之心""深造自得""左右逢源（本义褒）"。
- **万章（上下）**：论舜、论友、论圣人。**金声玉振**（孟子赞孔子集大成）出于下篇。
- **告子（上下）**：性善之辩、天将降大任、专心致志、先立乎其大。忧患意识最集中处。
- **尽心（上下）**：**取名密度与公孙丑并列**。三乐、浩然序列（充实→光辉→大→化）、穷达独兼、观澜、仁民爱物、德慧、成章、养心寡欲。

## 五、使用要点

1. **定位：与《论语》互补的"气象库"**。论语贡献德行词（敏行、思齐、文彬），孟子贡献气象词（浩然、大任、兼善、玉振）——一平实、一雄浑，志向型男名当以孟子为首选源典之一。
2. **浩然之气是跨千年的第一IP**：孟浩然（唐）→张养浩（元）→作家浩然（当代），证明该典的生命力；今日取名"浩""然"二字仍是高频字，但"浩然"全名重名率极高，可改用变体：**养浩、浩气、至刚、浩初**。
3. **"顶格"句式的风险**：孟子多"顶格"表达（舍我其谁、天降大任），入名气场强大，但对孩子而言可能压力过重；建议配中和性姓氏或取降格变体（大任→任之；兼善→善兼）。
4. **语境警示（孟子特有）**：不少名句整体在贬义/警示框架下——"生于忧患死于安乐""好为人师""自暴自弃""大而化之（今义）"，取字必须核对全句立场，谨防断章取义。
5. **女名富矿**：德慧、昭昭、仁声、恒爱、赤子、乐莫——孟子并非纯男性化源典，"仁民爱物"一系气质温润。
6. **与五行配伍**："浩""泉""澜""渊"皆水部，命中喜水者整组可用；"刚""毅"系（至刚）配金。

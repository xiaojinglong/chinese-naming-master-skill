# 《康熙字典》精读笔记

> 知识库 · 辞书工具书 18 ｜ 收字最全的古代字书——"字库边界"与笔画标准

## 一、书籍档案

| 项目 | 内容 |
|------|------|
| 性质 | 清代官修汉字辞书，中国古代收字最全的字书 |
| 编纂 | 康熙四十九年（1710）敕修，张玉书、陈廷敬等三十余人奉敕编；康熙五十五年（1716）成书 |
| 结构 | 42编：按十二地支分为12集（子丑寅卯辰巳午未申酉戌亥），每集又分上中下三卷 |
| 部首 | **214部首**（后世字典沿用至今），部首内按笔画排列 |
| 收字 | 正集47035字，另收备考、补遗字，总数约49000字 |
| 体例 | 每字先注音（反切＋直音＋叶音），次释义，再引书证 |
| 校订 | 清王引之《字典考证》正其引文错误2588条 |

## 二、结构精读

- **注音系统**：以《唐韵》《广韵》《集韵》《韵会》等历代韵书反切为主，直音为辅——一个字历代的读音流变可对照。
- **释义系统**：多义分列，各引古书为例——字的"义项族"一目了然。
- **检字法**：部首＋笔画，这套检字体系直接塑造了现代字典（现代《新华字典》仍用214部首的改良版）。

## 三、在取名工作流中的用途

### 1. 生僻字终审——"这个字存在吗"
客户提出或系统生成的任何冷僻字（如"龘""彧""翀"），以康熙字典做存在性与合法性双重校验：
- 收录且义项正常→可用（再看《通用规范汉字表》现代合规性）；
- 仅见于备考补遗→高风险（可能是讹字、死字），不建议入名。

### 2. 五格剖象法的笔画标准（重要！）
现代姓名学的"五格数理"（天格、人格、地格、总格、外格）**统一以康熙字典笔画计算**，且有繁体特则：
- 氵（三点水）按"水"算4画；扌（提手）按"手"算4画；艹（草头）按"艸"算6画；王字旁按"玉"算5画；阝左按"阜"8画、右按"邑"7画。
- 无论是否采用五格流派，做取名系统时必须内置"康熙笔画表"，因为这是行业默认算法。

### 3. 异体字正字辨别
"峯/峰"、"羣/群"、"菸/烟"——康熙字典的异体重文收录帮助辨别"同一个字的两种写法"，避免把异体当美体（户籍系统按规范字录入，异体字上不了户口）。

### 4. 义项核对（配合说文）
说文讲本义，康熙讲**义项全史**——选字时用康熙确认"这个字有没有不想要的引申义"（如"妍"有"争妍"的争竞义、"夭"有短折义）。

## 四、使用要点

1. **今字衔接**：康熙字典是古字书，最终用字合规以2013年国务院《通用规范汉字表》（8105字）为准——**流程建议：康熙定"是什么字"，规范表定"能不能上户口"**。
2. **引文可信度**：康熙字典引书有讹（王引之正2588条），引用其书证时重要条目需复核原书。
3. **注音干扰**：其"叶音"注法（为押韵临时改读）在现代语言学上是错误理论，读音以现代普通话审音为准。
4. **电子化**：已有多种电子版与在线版（汉典等网站底层即含康熙字典数据），适合做取名系统的字库底层数据源之一。

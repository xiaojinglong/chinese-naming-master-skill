## 二、结构精读

### 全书双维度框架

**纵向维度——简明"中国人名发展史"**：从上古（有名无字、以天干命名）到近现代的取名习俗演变规律，覆盖历代取名用字的艺术方式与文化特色，含字辈谱、生肖禁忌等技法的历史梳理。

**横向维度——中国"多名制"全体系**（本书最大特色）：

*生命个体维度*（不同生命阶段的人名符号）：

| 生命阶段 | 名号 |
|---------|------|
| 幼年 | 乳名（小名） |
| 成年 | 名＋字（"幼名冠字"） |
| 成年后自选 | 号（自号、别号） |
| 死后 | 谥号 |

*社会群体维度*（不同职业集团、社会阶层的特殊名号系统）：

| 社会身份 | 特殊名号 |
|---------|---------|
| 文人 | 室名（斋名）、笔名 |
| 艺人 | 艺名 |
| 僧道 | 法名、道号 |
| 皇帝 | 庙号、年号、谥号、讳号、尊号 |
| 士大夫 | 地望名、宦地名、官衔名、封爵名 |

### 内容要点

1. **取名的四大板块**：取名的历史、取名的艺术、取号的种种方法、不同人取名的禁忌。
2. **趣味切入点**（封底设问）：名与字的区别何在？能否根据名字判断一个人生活的时代？帝王各种称谓（庙号/年号/谥号/尊号）意义如何区分？**启功为什么不能给陈垣题写书名**？（避讳文化的活例——弟子为师题签须避师讳，可作"避讳三制"的现代延伸案例）
3. 附录收录**近现代学者名号对照表**——名、字、号、笔名纵横对照的实证数据。

### 核心观点

1. **取名传统比数理更重要**："要取得一个好名，《易经》数理、生肖干支固然重要，但如果不懂得几千年来中国人的命名文化，不知道中国人的取名传统，有时不免会闹出笑话。"——为"文化派"而非"术数派"张目。
2. 中国人名文化的历史积淀、内涵丰富度、形式多样性"世界上其他国家和民族无法比拟"。
3. 名、字、号的分工：名以正体，字以表德，号以美称（与李浩《流声》第二章框架一致，学界共识）。

## 三、对取名项目的价值

1. **多名制知识体系**：现代取名产品做"名＋字＋号"增值服务（如起名之外附赠斋号设计）的文化依据；"多名制"两维表可直接建为知识库的**名号体系数据结构**。
2. **历代取名习俗演变**：素材的时间轴框架——哪个朝代流行什么名字类型（先秦质朴→汉尚武功→魏晋之字→唐宋辈次→明清字辈），可支撑"仿古风格"取名需求与"根据名字判断时代"的展示功能。
3. **近现代学者名号对照表**：现成的名-字-号-笔名四元数据样本，可作结构化数据表的种子。
4. **名家案例的学术背书**：学院教授的典故考证可信度高，适合作为知识库的"史论层"。

## 四、使用要点

1. 本知识库"历史演变"内容与本书纵向维度直接对应，可互为引证；"启功避师讳"可补入避讳案例库。
2. 作者另有《华夏取名艺术》等前作，内容有重叠，取其一精读即可，本书为最晚期总结版。
3. 姊妹篇《谈姓氏》与本库20号《姓氏寻根与起名的艺术》题材重叠，择一即可。
4. 适合的读者：想系统理解"中国人为什么这样取名"的人——先读此书建立框架，再进入操作类书籍（宝宝起名全书等）。

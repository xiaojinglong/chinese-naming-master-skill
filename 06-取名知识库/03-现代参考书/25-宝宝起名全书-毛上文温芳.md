## 三、核心方法论

### 方法体系一览

| 方法 | 要点 |
|------|------|
| **五维全息起名法**（主打） | 五个维度整体策划名字（全书骨架，融合以下诸法） |
| NISS系统 | 起名策划识别成功系统——商标化的服务流程 |
| 八字五行起名法 | 依生辰八字推喜用神，五行补缺 |
| 十二生肖起名法 | 依属相喜忌选偏旁 |
| 八卦起名法 | 以《易经》八卦与三才配置命名 |
| 辈谱起名法 | 字辈谱排行命名 |
| 提炼诗词起名法 | 从诗词文赋中提炼萃取字词（典故起名法别名） |

### 本书立场（编辑推荐语还原）
"先天的八字五行是我们不可改变的要素，而后天的数理却是可以改变的……**有人起名不顾八字五行与姓名数理，只讲究十二生肖起名，这是以偏概全、舍本逐末的做法**"——虽含术数，但主张**综合多维、反对单一法**；"三象说"（意象/形象/音象）与谭汝为的语义/语音/用字、李浩的义/形/音三分法同构。

## 四、对取名项目的价值

1. **技法目录最全**：传统（八字/生肖/八卦/辈谱）与现代（五维全息/三象/提萃）方法一网打尽——资料库"取名方法论大全"的展开版，**可作取名系统"方法插件"的清单**。
2. **32个实例＝流程模板**：每案例展示完整决策链（姓氏分析→需求确认→方法组合→候选淘汰→定名）——**人机取名流程的黄金模板**；实例名单本身即"新中式雅名"的样本集（纾宁、伊南、枝蔻、明昕、浦瑞）。
3. **法律与谐音姓专题**：姓名权案例 + "姓吴起名难"文摘——取名系统必备的**合规检查与姓氏风险模块**的内容来源。
4. **繁体笔画标准章**：五格剖象法的工程基础（氵算4画、艹算6画等康熙笔画特则），与18号康熙字典文件构成"字库边界+笔画标准"闭环。
5. 持续迭代13年（2005→2025四版），实例审美随版次更新（新中式风格明显）。

## 四、使用要点

1. **命理成分提示**：八字、生肖、五格等术数方法在书中占比不低——科学性未获验证，工程上建议作为**可选开关**（尊重用户文化偏好）而非默认规则；默认规则应是音形义文化四维。
2. 与《诗里寻名》分工：本书给**流程与方法**（怎么策划一个名字），洪澜书给**素材与词条**（名字从哪来）。
3. 版本选择：直接用最新版（旧版实例与方法有代差）。
4. 实例中的复姓、四字名案例（欧阳明仑等）可供多字名设计参考。

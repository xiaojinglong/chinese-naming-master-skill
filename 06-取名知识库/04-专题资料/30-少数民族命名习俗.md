# 30 · 少数民族特色命名习俗

> **专题档案**｜来源：《取名数据2.txt》第六章 ＋ 2026-08-26 经网络搜索核实补深（百度百科、广西地情网、三明史志网、央视网、内蒙古日报、丽江纳西文化网等）
> **定位**：取名知识库的"多元库"维度——汉族取名规则之外，中国多民族命名制度的数据源。与 22-何晓明《中国姓名史》第十三章"中国少数民族姓名"互为表里。
> **用途**：为取名服务预留多元民族接口；理解不同民族的血缘传承逻辑、宗教信仰与自然观在命名中的投射。

---

## 一、总论：六大命名制式速览

中国少数民族命名制度远比汉族丰富，可归纳为**六大制式**：

| 制式 | 核心逻辑 | 代表民族 |
|------|---------|---------|
| **父子连名制** | 父名末字/音节作子名首字，世代相连成谱 | 哈尼族、彝族、纳西族、基诺族、景颇族、佤族 |
| **全名组合制** | 家族名+父名+母名+爱称+排行五要素合成全名 | 独龙族 |
| **多套名并行制** | 一生在不同人生阶段取多个名（乳名/世名/谱名/法名） | 畲族、瑶族 |
| **自然物命名制** | 以天地日月、花草树木、飞禽走兽为名 | 蒙古族 |
| **方位占卜命名制** | 依母亲属相、五行、九宫、巴格方位由东巴占卜取名 | 纳西族（摩梭人） |
| **排行+本名制** | 名分排行与本名两部分，排行用固定字序 | 佤族、壮族 |

> **共性**：少数民族命名普遍与宗教信仰（萨满、东巴、藏传佛教、原始崇拜）和血缘世系传承深度绑定；多数民族传统上"有名无姓"，姓氏是近代才出现或汉化后采用的。

## 二、哈尼族 · 父子连名制

### 1. 命名制度

哈尼族是**父子连名制**的典型代表。其基本原则：**父名的最后一个音节，用作子名的第一个音节**，世代顺推相连，形成可背诵上溯数十代的家族谱系。

- **谱系链例**：松山 → 山达 → 达飘 → …（每代首字承父名末字）
- **功能**：通过背诵家谱认宗族、辨亲属，最终可上溯至民族共同始祖"天母姆玛"
- **连名阶段**：前期二音节，中期三音节，后期复为二音节
- **女儿**：亦行父女连名（父名末音节作女儿名首音节），但出嫁后在夫家世系按父系计算，连名意义即失，**不列入谱系**
- **断代规则**：某代出现非正常死亡、双胞胎或生理缺陷者，不连父名，须逃过一代重新取名列代

### 2. 正名与副名

哈尼族名字分**正名**与**副名**：
- 平时称呼用**副名**；**正名**由家中老一辈人取，对外保密
- 正名取法有三：① **族谱名**（父子连名，列入祖宗谱系）；② **属相名**（按出生日属相）；③ **学名**（汉式名）
- 正名仅在背诵家谱、给小孩命名或隆重祭礼时使用

### 3. 支系差异

| 支系 | 取名特点 |
|------|---------|
| **吉维支系** | 按出生当天的属相取名，生在牛日取"牛×"，生在鸡日取"鸡×" |
| **吉坐支系** | 与"莫批"连名（大儿子死后，下面儿子名"批修"等） |
| 特殊情况 | 生在路途以"路"连名（嘎南）；怀孕期丈夫非正常死亡，婴儿以"罗"连名 |

### 4. 避讳与现代

- 后辈子孙**绝对不能与老辈、祖先同名**，否则视为不敬
- 现代哈尼族各支有自己的姓氏（哈尼语称"阿古"），但不普遍使用、不与名连用，仅在证明宗族归属时使用
- 如今亦取汉名，约定俗成如"当参阿古"用杨姓、"参先阿古"用李姓

## 三、独龙族 · 全名组合制

### 1. 全名五要素

独龙族**没有姓氏**，名字遵循特殊方式：以**家族名+父名+母名+爱称+排行**合成全名。

**女子全名例**：
> **白丽 · 丁板 · 顶 · 阿克洽 · 婻**
> （家族名·父名·母名·爱称·排行）

**男子全名例**：
> **孔当木 · 顶板 · 顶 · 阿克洽 · 旺**
> （家族名·父名·母名·爱称·本人名）

- 从名字即可判断：属于哪个家族、谁家的子女、在兄弟姐妹中排行第几
- **女子出嫁后不改家族名**（保留母系遗俗）

### 2. 排行用字

| 性别 | 排行用字（1→10） |
|------|----------------|
| **男子** | 朋、井、奎、今、顶、批、筒、菜、托木、顶那 |
| **女子** | 能、捻、嫱、奈、钦… |

- 最小的两个儿子排行用词为**达绕、达马**

### 3. 命名时机与家族名来源

- **男孩出生后第7天命名，女孩第9天命名**
- 家族名多用**地名/自然环境特征**命名：如"孔当"（宽大的坝子）、"龙棍"（石头多的地方）；也有用家族长名字命名的，如"木千王""木千图"
- 独龙族尚未形成以父亲名为主的父子连名制，**仍保留母子（女）连名遗迹**

## 四、畲族 · 多套名并行制

### 1. 男子一生四名

畲族男子一生有**乳名、世名、讳名、法名**四个名：

| 名类 | 取得时机 | 用途 |
|------|---------|------|
| **乳名** | 幼年 | 日常称呼 |
| **世名** | 由族长按辈分排定 | 社会交往，墓碑所刻 |
| **讳名** | — | 讳称 |
| **法名** | 成年参加祭祖"招兵"宗教活动后取得 | 宗教法事 |

- 女子一般只有**乳名及讳名**
- 死后：男人称"郎"或"公"，女人称"娘"（墓碑刻世名，如"千三公""万六公"）

### 2. 辈序排行（"暗行"）

畲族传统辈序以**"大、小、百、千、万"五字轮回**，周而复始，称"世名"：

| 姓氏 | 辈序（轮回顺序） |
|------|----------------|
| **蓝姓** | 千、万、大、小、百 |
| **雷姓** | 大、小、干、百、万 |
| **钟姓** | 大、小、百、万、念（无"千"，易为"念"） |

- 各姓辈序有差异，**为避免同姓近亲结婚**
- 男丁排行序数从二开始（"蓝念二郎""蓝念三郎"），女丁从一开始且缺二（"蓝念一娘""蓝念三娘"）——将"一郎"和"二娘"让给未满16岁夭折的男女

### 3. 谱名的神秘性

- 畲族谱名带有**神秘性**：晚辈对自身讳字行第**不得而知**，仅在祭祖或重修宗谱时才能阅看
- 人逝世时，亲属须向族长索取谱名；外嫁女做"寿材"（棺木）需"名行"与"暗行"时，由兄弟向族长索要，红纸封好待启封

### 4. 汉化与五行补缺

- 清代乾隆年间起吸收汉族排辈法，如蓝氏"友、元、奕、世、德、如、真、全"八字排辈
- 五行补缺：算命先生说缺"金"，辈分字为"志"，则取名"志鑫"；缺"水"取"志水""志淼""志河"

## 五、瑶族 · 多套名并行制（含法名）

### 1. 盘瑶一生三名

瑶族（以盘瑶为例）一生一般取**乳名、书名、法名**三个名：

| 名类 | 取得时机 | 特点 |
|------|---------|------|
| **乳名** | 出生时 | 男孩加"阿"（如"阿议""阿沸"），女孩加"梅"（如"梅翻"）；也有按出生顺序"一、议、翻、沸、娩" |
| **书名** | 入学后 | 嵌入辈分字，相当于汉族大名 |
| **法名** | 度戒后 | 宗教仪式专用，平常不用 |

### 2. 法名与度戒

- 男子长到十五岁后，可请巫师"师公"来家作法**度戒**，度戒后取**法名**
- **盘瑶法名**：第一字多为"法"，如"赵法旺""盘法现"
- **茶山瑶**：度戒后成为师公通用"胜"或"法"，成为道公用"玄"或"道"
- **法名一般生前不用，死后才记入《家先书》**（家谱）
- 经更高一级"加职"仪式可取"郎"的称号，如"赵胜二郎"（"二"表兄弟排行第二）

### 3. 俗名的四阶段

瑶族男子俗名随人生阶段变化（以金秀瑶族为例）：
1. **乳名**：出生第三天取
2. **结婚名**：结婚次日，若妻名"小兰"，则被称为"兰郎"
3. **孩名**：生第一子后，若子名"小梅"，则被称为"梅发"（梅爸）
4. **孙爷名**：第一孙出生后，若孙名"小莉"，则称"莉高劳"（小莉爷）

### 4. 八排瑶全名六要素

广东连南八排瑶的姓名制度极完善，全名含**六部分**：

| 要素 | 含义 |
|------|------|
| ① 姓 | 家族血缘标志 |
| ② 房族名 | 同姓下分房族（始祖同胞兄弟划分而来） |
| ③ 父名 | 父子连名制遗存 |
| ④ 本人名 | 私名，多取身体特征或动植物名 |
| ⑤ 排行名 | 出生顺序（一、二、三…） |
| ⑥ 婚姻子女状况 | 随性别年龄变化 |

> 一个人的社会地位可在姓名中清晰反映——血缘、家族、家庭、排行、性别、子孙情况乃至身体特征。

## 六、蒙古族 · 自然物命名制

### 1. 命名六大类

蒙古族传统上**有名无姓**（姓与名不连称），以自然万物为名，体现游牧民族对大自然的崇拜：

| 类别 | 命名方式 | 典型名字 |
|------|---------|---------|
| **花草树木** | 直接称谓或复合 | 那日苏（松树）、其其格（花）、巴德玛（莲花）、赛罕其其格（美丽的花） |
| **日月星辰** | 天体崇拜 | 腾格尔（苍天）、娜仁（太阳）、萨仁（月亮）、奥敦（星星）、娜仁高娃（太阳般美丽） |
| **飞禽走兽** | 崇拜或喜爱 | 巴日斯（虎）、阿日斯楞（狮）、布日古德（鹰）、陶格斯（孔雀）、呼日嘎（羔羊） |
| **山川河流** | 地理崇拜 | 朝鲁（石头）、阿古拉（山）、牧仁（河）、塔拉（原野） |
| **长辈期望** | 祝愿式 | 吉雅赛音（好运）、巴雅尔（喜悦）、白音（富足）、吉日格勒（幸福） |
| **长辈年龄** | 纪年式 | 塔宾（五十）、吉仁泰（六十）、达楞（七十） |

### 2. 女子命名四类

| 类别 | 典型名字 |
|------|---------|
| 星辰 | 娜仁（太阳）、萨仁（月亮）、敖敦（星辰）、萨仁高娃（月亮般美） |
| 花草 | 萨日朗花（山丹花）、其其格（花）、娜布其（叶） |
| 珠宝 | 哈斯（玉）、塔娜（珍珠）、阿拉坦高娃（金子般美） |
| 理想 | 斯琴（聪颖）、乌云（智慧）、高娃（美丽）、斯琴高娃（聪慧美） |

### 3. 贬义乳名与宗教名

- 有的蒙古人会给孩子起**贬义乳名以避邪**：哈日淖海（黑狗）、毛淖海（赖皮狗）、毛易汗（丑姑娘）
- 因信奉藏传佛教，部分人用**藏语或经藏语传承的梵文**命名：多吉/道尔吉（闪电）、达尔扎；也有以一周七天出生日命名（周一"达瓦"等，源自藏语）
- 现代蒙古国受俄国影响，有人取俄式名

### 4. 文化内核

> "天父地母"思想根深蒂固——崇敬自然、热爱一切生灵的情愫融入血液。给下一代取的名字，就是最好的见证。

## 七、纳西族 · 方位占卜命名制（"名又"制）

### 1. "名又"——给名字

"名又"为纳西语，即**"给名字"**，是纳西族家族制习俗。婴儿降生当天或第二天，请**东巴、达巴或喇嘛**举行命名仪式：

1. 将鸡肉、猪肉、饭团等供于灶神前祭祖先
2. 进行**占卜**：依据母亲年龄、属相，及孩子出生的年月日时，推算属八卦上的哪个方位
3. 将与孩子方位一致的**神佛名字**取两个字挂上，祈神佛保佑
   - 如东方神"都吉沙玛"、南方神"尔车独基"，东南角出生可取名"独支玛""独基甲泽"

### 2. 属相方位取名

也有不带神佛名，仅以婴儿属相及诞生方位取名的：
- 东北方为牛方：男孩取名"依若"（"依"=牛，"若"=男），女孩取名"依木"（"木"=女）

### 3. 重名与区分

因按八卦方位取名，**一村甚至一家之中常有相同名字**，为此常在名字前冠以：
- **家名**：如阿纳·梭拉直马、日布·梭拉直玛
- **"大""小"**：如大直玛、小直玛，以示区别

### 4. 古代父子连名

云南丽江纳西族古代曾盛行**父子连名或母女连名制**，如木氏土司宗谱：
> 阳音都谷 → 都谷刺具 → 刺具崇将 → …（每代后两音节承父名前两音节）

- 明代以后开始取汉名，至今除乳名外一般用汉名
- 中甸、宁蒗一带仍保留本民族名字

## 八、对取名项目的价值

1. **多元接口**：汉族取名服务若面向少数民族用户，需理解其本民族命名制式（如哈尼父子连名、瑶族法名），不可简单套用汉式规则。
2. **制式启发**：
   - 父子连名制 → **世系可编程的命名算法**（父名末字→子名首字，可自动生成谱系链）
   - 多套名并行 → **人名生命周期管理**（乳名→学名→法名，随人生阶段切换）
   - 自然物命名 → **意象取名的极致案例**（蒙古族将"以物为名"发挥到系统化）
3. **与汉文化的对照**：
   - 汉族"字辈谱"是**纵向辈分字固定**；畲族"大小百万"五字轮回是**横向辈分循环**——两种不同的辈分编码逻辑
   - 汉族"五行补缺"是**个人命理**；朱熹家族"五行序辈"是**家族世代**——两种五行用法（详见 32-字辈谱与五行序辈）
4. **数据源**：22-何晓明《中国姓名史》第十三章为本节学术骨架；本节为实例化展开。

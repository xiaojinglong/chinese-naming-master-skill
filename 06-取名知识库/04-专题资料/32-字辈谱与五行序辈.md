> **用途**：字辈取名法的"字库"与"算法"；家族世代命名的编码逻辑；五行相生在家族命名中的系统化应用。

## 一、字辈谱起名法（行辈取名法）

### 1. 定义与原理

- **定义**：同一宗族同一辈分的人，名字中有一字相同，以明世系、别长幼。
- **形成**：唐宋以后逐渐形成，明清最为盛行。
- **编码逻辑**：名字第一字（或指定位置字）= 辈分字，由家族预先排定的**字辈序列**中按世代顺序取字。

### 2. 孔子世家字辈谱（最经典的字辈谱）

孔氏家族自第56代起使用统一字辈，是**天下字辈谱的标杆**，孔孟颜曾四姓共用：

#### 第一批（明初，朱元璋赐/经朝廷认可）

| 世代 | 字辈 |
|------|------|
| 56-60代 | **希、言、公、彦、承** |
| 61-65代 | **宏、闻、贞、尚、衍** |

> 据载，明洪武元年（1368年），朱元璋赐孔氏八字辈"公、彦、承、弘、闻、贞、尚、胤"，后因避清讳（胤→衍）等调整。

#### 第二批（清代乾隆年间增补）

| 世代 | 字辈 |
|------|------|
| 66-70代 | **兴、毓、传、继、广** |
| 71-75代 | **昭、宪、庆、繁、祥** |

#### 第三批（民国九年即1920年，北洋政府批准续增20字）

| 世代 | 字辈 |
|------|------|
| 76-80代 | **令、德、维、垂、佑** |
| 81-85代 | **钦、绍、念、显、扬** |
| 86-90代 | **建、道、敦、安、定** |
| 91-95代 | **懋、修、肇、懿、长** |
| 96-100代 | **裕、文、焕、景、瑞** |
| 101-105代 | **永、锡、世、绪、昌** |

#### 完整字辈谱连读

> 希言公彦承，宏闻贞尚衍。
> 兴毓传继广，昭宪庆繁祥。
> 令德维垂佑，钦绍念显扬。
> 建道敦安定，懋修肇懿长。
> 裕文焕景瑞，永锡世绪昌。

- **使用方式**：孔氏后人取名时，按所属世代从字辈谱中取对应字，嵌入名字指定位置（通常为首字）
- 如第76代孔令贻（"令"字辈）、第77代孔德成（"德"字辈）

### 3. 其他著名字辈谱实例

| 家族 | 字辈（节选） | 特点 |
|------|-------------|------|
| **宋太祖赵匡胤后裔** | 德、惟、从、世、令、子、伯、师、希、与、孟、由、宜 | 每一辈占一字，13字 |
| **杨业八子** | 延平、延定、延光、延辉、延昭、延郎、延兴、延玉 | 同辈"延"字排名 |
| **明皇室（字辈+五行）** | 见下文五行序辈 | 字辈与五行结合 |

## 二、五行序辈起名法

### 1. 定义与原理

- **定义**：家族世代取名时，按**五行相生**（木→火→土→金→水→木→……）的顺序，在名字中使用对应五行偏旁的字。
- **相生关系**：木生火、火生土、土生金、金生水、水生木
- **编码逻辑**：五行字 = 世代标识，既贯穿世系又能区分辈分——比纯字辈谱多一层"五行哲学"的宇宙观

### 2. 历史溯源

| 时期 | 家族 | 五行链 | 地位 |
|------|------|--------|------|
| **唐代** | 毕构家族 | 毕栩（木）→毕炕（火）→毕坰/毕增（土） | **史上最早按五行起名的记录** |
| **宋代** | 朱熹家族 | 松（木）→熹（火）→塾/埜/在（土）→钜/钧/鉴（金）→洽/济/浚/潜（水） | 最著名的五行序辈实例 |
| **宋代** | 秦桧家族 | 彬/梓/棣（木）→熺（火）→埙/堪/坦（土）→钜（金） | 与朱熹同期 |
| **宋代** | 张浚家族 | 张浚（水）→张栻（木）→张焯（火） | 水生木、木生火 |
| **明代** | 朱明皇室 | 见下文 | 制度化巅峰 |

### 3. 朱熹家族五行序辈链（详解）

经人民网、凤凰网、今日头条多源核实：

| 世代 | 人名 | 五行 | 偏旁说明 |
|------|------|------|---------|
| 第一代（父） | **朱松** | 木 | "松"字木字旁 |
| 第二代 | **朱熹** | 火 | "熹"字下四点为"火"形（本义"炙"） |
| 第三代（子） | **朱塾、朱埜、朱在** | 土 | "在"字内含"土" |
| 第四代（孙） | **朱钜、朱钧、朱鉴** | 金 | "鉴"等金字旁 |
| 第五代（曾孙） | **朱洽、朱济、朱浚、朱潜** | 水 | "浚""潜"水字旁 |
| 第六代 | **朱林** | 木 | 循环回到木 |
| 第七代 | **朱炣** | 火 | 循环 |
| 第八代 | **朱塈** | 土 | 循环 |

> **朱氏一门五代**（松→熹→塾→鉴→浚）占五行相生五字（木→火→土→金→水），贯穿世系又区分辈分——"严谨、巧妙，颇具匠心"。

### 4. 朱元璋皇室五行相生法（制度化巅峰）

朱元璋将五行相生法发扬光大，规定子孙取名须用五行字：

- **第一代**：朱元璋本人（名字不带五行，为始祖）
- **第二代起**：从第三代起**二字名**——上一字表辈分（字辈），下一字为五行字

| 世代 | 皇帝 | 五行 | 名字 |
|------|------|------|------|
| 第三代 | 成祖 | 木 | 朱**棣** |
| 第四代 | 仁宗 | 火 | 朱高**炽** |
| 第五代 | 宣宗 | 土 | 朱瞻**基** |
| 第六代 | 英宗/代宗 | 金 | 朱祁**镇**/朱祁**钰** |
| 第七代 | 宪宗 | 水 | 朱见**深** |
| 第八代 | 孝宗 | 木 | 朱佑**樘**（循环回木） |
| 第九代 | 武宗/世宗 | 火 | 朱厚**照**/朱厚**熜** |
| 第十代 | 穆宗 | 土 | 朱载**垕** |
| 第十一代 | 神宗 | 金 | 朱翊**钧** |
| 第十二代 | 光宗 | 水 | 朱常**洛** |
| 第十三代 | 熹宗/思宗 | 木 | 朱由**校**/朱由**检**（循环回木，第三个循环开始） |

> **用意**：让"五行相生"链保佑大明江山在子孙中代代相传、循环不止。然而，明王朝最终被能克"明"火的"清"水所取代——"未能逃脱五行相克的历史规律"。
>
> **命名价值**：一看名字即知辈分与世系——如看"朱翊钧"便知是燕王房"翊"字辈、五行属金。

### 5. 五行补缺 vs 五行序辈（两种不同用法）

| 维度 | 五行补缺（个人命理） | 五行序辈（家族世代） |
|------|---------------------|---------------------|
| **对象** | 个人 | 家族世代 |
| **依据** | 生辰八字推算个人五行缺什么 | 五行相生顺序排辈 |
| **方法** | 缺水取"氵"旁字，缺木取"木"旁字 | 父木→子火→孙土→…… |
| **实例** | 缺金取"鑫"，缺水取"淼" | 朱松(木)→朱熹(火)→…… |
| **来源** | 见取名规则.txt 第五节 | 本文件 |

> 详见 **取名规则.txt** 第五节"命理与生肖禁忌"（五行补缺），与本文件（五行序辈）配合使用。

## 四、对取名项目的价值

1. **字辈取名算法**：
   - 输入家族字辈谱 + 当世代数 → 输出该世代的辈分字
   - 字辈字 + 自选字 = 完整名字
2. **五行序辈生成器**：
   - 输入当前世代五行 → 输出下一世代五行（相生关系：木→火→土→金→水→木）
   - 五行 + 偏旁字库 → 候选字集
3. **与知识库联动**：
   - 字辈谱演变 → **19-王泉根《姓名的奥秘》**（上古至明清字辈谱演变）
   - 辈谱起名法 → **25-毛上文《宝宝起名全书》**（辈谱起名法流程）
   - 五行补缺 → **取名规则.txt** 第五节
   - 历史背景 → **31-历史演变时间轴.md**（两宋/明清时代）
4. **改名/续谱服务**：家族续修家谱时，可按字辈谱为新生儿取名；断谱家族可参考同姓字辈谱补续。

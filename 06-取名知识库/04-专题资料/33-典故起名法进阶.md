## 一、典故寓意起名法 · 三种用典方式

从古典诗词文赋中选取富有真善美意蕴的字词组合成名，是取名最主流的方法。按用典方式可分为三类：

### 1. 明典（直接摘取）

- **定义**：直接从诗文原句中摘取字词入名，字面与出处一致。
- **特点**：出处可查、字义明确，是"女诗经男楚辞"传统的主流方式。
- **实例**：

| 名字 | 出处 | 原句 | 寓意 |
|------|------|------|------|
| 思成 | 《诗经·商颂·那》 | "绥我思成" | 心中所愿皆能成就（梁思成） |
| 徽音 | 《诗经·大雅·思齐》 | "大姒嗣徽音" | 继承美德美誉（林徽因原名） |
| 邦彦 | 《诗经·郑风·羔裘》 | "彼其之子，邦之彦兮" | 国家俊杰（周邦彦） |
| 斯年 | 《诗经·大雅·下武》 | "于万斯年，受天之祜" | 国运绵长（傅斯年） |
| 朝闻 | 《论语·里仁》 | "朝闻道，夕死可矣" | 对真理的极致追求（王朝闻） |
| 怀德 | 《论语·里仁》 | "君子怀德" | 君子心怀仁德（彭德怀） |

### 2. 暗典（提炼意境）

- **定义**：提炼诗文的意境或主题，不直接照搬原字，而是用其他字表达相近意蕴。
- **特点**：含蓄蕴藉，需了解典故背景才能体会深意；避免直白浅露。
- **实例**：

| 名字 | 典故来源 | 意境提炼 | 说明 |
|------|---------|---------|------|
| 朝雨 | 王维《渭城曲》"渭城朝雨浥轻尘" | 清新送别之意 | 不取"渭城"或"浥尘"，取"朝雨"表清新意象 |
| 冰心 | 王昌龄《芙蓉楼送辛渐》"一片冰心在玉壶" | 冰清玉洁之操守 | 提炼"冰心"意象而非直取全句 |
| 云帆 | 李白《行路难》"直挂云帆济沧海" | 乘风破浪之志 | 取"云帆"表远航抱负 |

### 3. 以德立志（寄托品德志向）

- **定义**：以品德、志向、祈愿为命名意图，不一定出自具体诗文，而取德行字入名。
- **特点**：直抒胸臆，寄托父母期望，是最古老的取名意图之一（对应先秦"五类"中的"有义"）。
- **实例**：

| 人物 | 名/字 | 命名意图 |
|------|-------|---------|
| 曹操 | 字**孟德** | 以"德"命名（品德） |
| 刘备 | 字**玄德** | 以"德"命名 |
| 诸葛亮 | 字**孔明** | 以"明察"立志 |
| 赵云 | 字**子龙** | "云从龙"（《周易》）以龙立志 |
| **司马相如** | 改名**相如** | 原名"犬子"，仰慕战国名相蔺相如之为人而改名——**"慕名改名"**的经典案例 |

> **慕名改名**：司马相如案例展示了一种特殊的以德立志——不取德行字本身，而**直接袭用仰慕人物之名**。这与避讳制度（忌与先贤同名）形成张力：汉代尚无严格避前人名的禁忌，故"慕名"可行；现代取名则一般不以伟人、名人名字为名（见取名规则.txt 第三节禁忌16-17）。

> **三种方式的选用建议**：明典适合追求文化底蕴与出处可查；暗典适合追求含蓄雅致与个性表达；以德立志适合寄托直白期望。三者可结合使用。

## 二、三才五格 · 笔画数理姓名学

### 1. 定义与流派归属

- **三才五格**是**现代姓名学流派**的核心理论，结合姓名笔画数理定吉凶。
- 属"术数类"起名法（取名规则.txt 中归类为"命理与生肖"维度）。
- 与传统"典故起名法""字辈起名法"不同，三才五格侧重**笔画数理的吉凶配置**。

### 2. 五格构成

| 格 | 计算方式 | 含义 |
|----|---------|------|
| **天格** | 姓氏笔画数 + 1（单姓）；或两姓笔画之和（复姓） | 祖上运、先天根基 |
| **人格** | 姓氏末字笔画 + 名字首字笔画 | 主运、核心性格（最重要的一格） |
| **地格** | 名字笔画之和（双名）或 名字笔画 + 1（单名） | 前运、青少年时期 |
| **总格** | 姓名全部笔画之和 | 后运、中晚年 |
| **外格** | 总格笔画 - 人格笔画 + 1 | 外运、人际社交 |

### 3. 三才配置

- **三才** = 天格、人格、地格的**五行属性配置**
- 各格笔画数的尾数对应五行：1/2→木，3/4→火，5/6→土，7/8→金，9/0→水
- 三才配置讲究**相生为吉、相克为凶**

### 4. 数理吉凶

- 笔画数理分吉数与凶数（如 1,3,5,8,11,13,15,16,21,23,24,25,31,32,33,35 等为吉数）
- 五格均需落在吉数，且三才配置相生

### 5. 注意事项

> **本节定位**：三才五格属现代姓名学的术数流派，笔画计算须用**康熙字典笔画**（非简体笔画）。知识库中 **18-康熙字典.md** 为笔画标准依据。
>
> **与取名规则的关系**：取名规则.txt 已将五行生肖归入"命理"维度；三才五格是其现代数理化的发展。传统取名更重"音形义"，三才五格为补充参考。

## 三、生肖起名法 · 喜忌偏旁细则

### 1. 基本原理

- 参照十二生肖属相，规避生肖冲害，选取与生肖相宜的字
- 生肖与地支相配，地支有**相合、相冲、相害**关系
- 起名应使用属相**喜欢**的字及**三合三会**的字，避免**相冲、相害**的字

### 2. 各生肖喜忌偏旁（精选）

| 生肖 | 喜用偏旁/字根 | 忌用偏旁/字根 | 理由 |
|------|--------------|--------------|------|
| **鼠** | 口、宀（洞穴屋檐） | 辶、廴（被困/被追） | 鼠喜洞穴藏身，忌被困 |
| **牛** | 艹、禾、田（食草耕田） | 马、羊（丑午相害、丑未相冲） | 牛食草耕田为喜 |
| **虎** | 山、林（称王之地） | 辶、廴（被困） | 虎据山林称霸 |
| **兔** | 艹、禾（食草） | 鸡（卯酉相冲） | 兔食草为喜 |
| **龙** | 水、氵、雨（龙腾云水） | 狗（辰戌相冲） | 龙喜水腾云 |
| **蛇** | 田、艹（蛇行田野） | 猪（巳亥相冲） | 蛇喜田野潜行 |
| **马** | 艹、禾（食草） | 鼠（子午相冲） | 马食草为喜 |
| **羊** | 艹、禾（食草） | 牛（丑未相冲） | 羊食草为喜 |
| **猴** | 木、禾（猴栖树林食果） | 虎（寅申相冲） | 猴喜树林 |
| **鸡** | 禾、米、豆（食五谷） | 兔（卯酉相冲） | 鸡食五谷 |
| **狗** | 人、亻（忠主） | 龙（辰戌相冲） | 狗忠主为喜 |
| **猪** | 艹、禾、米（食五谷草） | 蛇（巳亥相冲） | 猪食五谷草为喜 |

### 3. 三合三会

- **三合**：申子辰（猴鼠龙）、亥卯未（猪兔羊）、寅午戌（虎马狗）、巳酉丑（蛇鸡牛）
- **三会**：寅卯辰（虎兔龙东方木）、巳午未（蛇马羊南方火）、申酉戌（猴鸡狗西方金）、亥子丑（猪鼠牛北方水）
- 起名宜用与本命生肖**三合三会**的字根

### 4. 注意事项

> 生肖起名法属民俗传统，不同流派细则略有差异。本表为常见说法的精选汇总，实际应用时建议结合具体命理八字综合判断。

## 四、对取名项目的价值

1. **技法辨析**：明典/暗典/以德立志三种用典方式，是取名"技法库"中"典故起名法"的细分——避免笼统说"从诗词取名"，而能区分用典层次。
2. **数理流派数据**：三才五格为现代姓名学提供笔画数理的"计算规则"，可与 28-李正明的20算子结合，实现"典故生成 + 数理校验"的取名流程。
3. **生肖字库**：生肖喜忌偏旁表为生肖起名法提供**选字/筛字规则**，可与 17-骈字类编（按意象门类选字）联动。
4. **工作流补充**：本节补充取名标准工作流第4步（字词生成）与第5步（音形义校验）的技法细节。

## 数据口径说明（重要）

1. **笔画数**：姓名学以**繁体字形 + 康熙字典笔画**为准（如「明」8画、「磊」非18画等特殊字须查康熙字典）。简体笔画仅作参考字段。
2. **五行属性**：汉字五行存在多种分法（笔画数五行/字义五行/音律五行/字形五行），本库采用**字义五行为主、笔画五行为辅**的常见取法，并在字段中标注来源口径。
3. **吉凶判定**：三才五格的吉凶标准在不同流派（如熊崎健翁派、三才派）略有差异，本库采用流传最广的标准版，实际使用时建议以主流姓名学书籍交叉核对。
4. **八字排盘**：月柱以**节令（节气）**为界，非农历初一；日柱按公历日期经公式推算（有标准算法，见规则文档）。
5. **生肖喜忌**：属于传统民俗范畴，不同资料版本存在差异，本库按通行版本整理，并在文档中注明版本来源。

## 使用建议

- 开发 Skill 时，数据文件直接用 JSON 加载；规则文档用于编写判定逻辑与提示词。
- **字库选择**：
  - 快速取名（默认）：`hanzi_common.json`（308 常用字，字段最全，含性别/生僻/谐音标注）
  - 全面筛选（生产）：`hanzi_full.json`（18,821 字，支持任意五行/笔画/部首筛选；**康熙笔画已全量接入，覆盖率 98.8%**，可直接计算五格）
- **三才吉凶**：主用 `sancai_full.json`（原文断语版，125 组完整解释），`sancai_125.json`（推导版）作交叉参考。
- 评分权重配置 `06-评分权重配置.json` 支持调整，默认值可参考 `02-规则与算法资料/06-候选名字评分规则.md`。
